## 1. 角色职责与边界

### 1.1 本规格管什么

| 域 | 内容 |
|---|---|
| 用户端契约 | 会话与 workspace 绑定、跨 workspace 可见性的对客规则、移除 vs 删除、恢复后横幅、模式徽章与待审批状态 |
| 审批用户体验 | 参数可见与兜底、风险分档（保守档 / 敏捷档）、禁止自研 allow-always、全局收件箱、超时文案 |
| SKU 与隔离承诺 | 企业版 / 团队版 / 个人版 / 共享域档；"需隔离者分属不同租户或隔离组"的对客表述；否决单租户多自然人 |
| 删除承诺 | 端点命名与默认值、生效时延、撤销窗口、用户可见文案、删除报告 |
| 计费与配额商业化 | 软配额合同条款、80% 预警与自助扩容、`GET /v1/usage` 对外口径、L1b 对客话术、公平性对客承诺 |
| 成本与定价 | 客户画像毛利率、4 画像 × 3 档单位经济矩阵、定价结构（不做纯 seat）、报价先于签约 |
| 签约前置要件 | SLA / 赔偿 / 维护窗口 / 数据驻留声明 / 租户数据导出 / SSO-SCIM |
| 上市判据 | 首批客户 MVP 保留清单与可砍项清单 |

## 2. 规范性条款

### 2.1 用户端契约（一会话一工作区 · 可见性规则 · 移除≠删除 · 恢复横幅 · 状态可见）

|---|---|---|---|---|---|

| `PRD-004` | 必须 | 移除与删除**必须**是两个动作、两个名字、两个确认级别：<br>① `POST /v1/workspaces/{id}:unregister` = **移除注册**，**不删除**文件夹、文件或会话历史；<br>② `DELETE /v1/workspaces/{id}` = **删除数据**，**默认即真删**，须二次确认 + 7 天撤销窗口；<br>③ `DELETE /v1/sessions/{id}` = 仅删除会话历史，**不动** workspace 数据 | ① 接口签名的 `:unregister` 后缀与 `DELETE` 方法与本条款逐字一致；② 调用 `:unregister` 后 `GET /v1/workspaces/{id}/files/{path*}` 仍返回原文件；③ 调用 `DELETE /v1/workspaces/{id}` 在撤销窗口内可撤销并恢复；④ UI 上两个动作的按钮文案与二次确认文案不同（见 `PRD-005`） | §6.1（删除语义反转：移除用 `:unregister`，删除用 `DELETE`）；`C32`；§7.5 | 上线前检查表（OpenAPI 快照 diff + UI 控件文本）；产品材料评审 |

| `PRD-006` | 必须 | 中断或跨实例恢复后，产品**必须**在会话页注入**系统级横幅**（不可被用户关闭后永久消失，仅可折叠为常驻标记），使用**逐字**文案：<br>「本次恢复后，之前的**终端状态与后台任务已丢失**；请先核验外部状态再继续。」 | ① 恢复路径（`kill -9` 后续跑）触发后横幅出现；② 关闭/折叠后会话页仍保留常驻标记，直到用户显式确认"已核验"；③ 文案字符串比对一致 | §7.3.5 第 4 条；§7.4 不可恢复清单；`C22`；`C2` | 上线前检查表（恢复演练录像 + 截图）；演练门禁（`PRD-006` 纳入最小演练集的可视化检查项） |

### 2.2 审批用户体验（参数可见 · 风险分档 · 禁止自研 allow-always · 收件箱 · 超时文案）

|---|---|---|---|---|---|
