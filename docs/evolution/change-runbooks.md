## 0. Runbook 通用结构（五本共用）

| # | 部分 | 硬性要求 |
|---|---|---|
| 1 | 触发条件 | 可判定；写清"什么事件触发本 Runbook" |
| 2 | **必填项清单** | **缺项即阻断执行**；执行前逐项勾选并留证 |
| 3 | 步骤表 | 列固定为：`步骤` / `动作` / `判定` / `失败处置` / **`回退`** |
| 4 | 验收项 | 逐项可判定，不得写"检查通过" |
| 5 | 产物 | 落库位置与签名要求 |
| 6 | 禁止步骤 | 出现即判该次执行为**不合格**（不是"下次注意"） |

**通用规则**

| # | 规则 |
|---|---|
| R-1 | 步骤**不得**跳步、**不得**部分推进；任一步失败即进入其"回退"列 |
| R-2 | 回退**必须**有明确入口与必填参数；无回退路径的步骤**必须**在表中显式写"无回退（须前置验证）" |
| R-3 | 所有证据来源**必须**域外；域内自报只作交叉核验 |
| R-4 | 不以任何具体机器或现有部署作为判定基准 |

| 步骤 | 动作 | 判定 | 失败处置 | 回退 |
|---|---|---|---|---|
| 1 | 容量评审：给出域数、每域会话上限、拆分方案 | 输出含"拆分点" | 不合格（**不得**只输出"加大内存 / CPU"） | 取消扩容，维持现状 |

| 3 | 若走 ①：新建隔离组 / 多域，逐批纳入（同租户不跨批） | 批次校验通过 | 拒绝推进 | 回退已纳入的域 |
| 4 | 逐域迁移会话：先过 preset 子集判定，再走迁移状态机 | `目标域可解析集合 ⊇ 全集`；迁移状态机断言通过 | 排除该目标域并记审计；给出缺失 id | 目标域释放租约，路由回到源域 |

| 6 | 若走 ②：更新报价与签约模板 | 条款写明"不支持"与边界 | 报价门禁不通过 | 回到步骤 1 |

## 5. RB-05 监管变更

| 项 | 值 |
|---|---|
| 触发条件 | 新增 / 变更监管约束（保留期 / 驻留区域 / 加密与密钥约束 / 审计留存） |
| 落实需求 | `EVO-036`；交叉 `EVO-026`、`EVO-029`、`EVO-030`、`EVO-031` |
| 硬性时窗 | **≤ 30 天**内转成一个**声明式合规 Profile 变更**并被验证 |

### 5.1 必填项清单（缺项即阻断执行）

| # | 必填项 | 形态 | 缺失后果 |
|---|---|---|---|
| 1 | 监管约束清单（逐条：保留期 / 驻留区域 / 加密与密钥约束 / 审计留存） | 结构化条目 | 阻断 |
| 2 | 合规 Profile 变更（**声明式**，不得改数据结构） | Profile 差异 | 阻断 |
| 3 | 租户映射变更（区域绑定 / 保留期档位） | 映射差异 | 阻断 |
| 4 | 合规 Profile 的 schema 校验结果 | 校验报告 id | 阻断 |
| 5 | **全租户符合性报告**（列出不符合项与租户） | 报告 id | 阻断 |
| 6 | 落地时窗证据（约束发布日 → Profile 生效日 ≤ 30 天） | 时间戳 | 阻断 |
| 7 | 若涉及密钥约束：双证书重叠期参数与轮换预演记录 | 轮换配置 + 预演记录 | 阻断 |

### 5.2 步骤表

| 步骤 | 动作 | 判定 | 失败处置 | 回退 |
|---|---|---|---|---|
| 1 | 约束转译：把监管条文转成合规 Profile 字段（保留期 / `residencyRegion` / 加密约束 / 审计留存） | 每条约束有对应字段 | 阻断；**不得**以改代码替代 | 回到步骤 1 |
| 2 | 提交声明式 Profile 变更并过 schema 校验 | 校验通过 | 阻断生效 | 撤回变更（Profile 保留旧值） |
| 3 | 更新租户映射（受影响的租户 / 区域 / 档位） | 映射可回放 | 阻断 | 恢复旧映射 |
| 4 | 生效并观察：域启动断言 `residencyRegion` 一致性 | 断言通过；不一致域拒绝 ready | 摘域或修正 Profile | 回退到旧 Profile |
| 5 | 生成**全租户符合性报告** | 报告列出不符合项与租户 | 阻断收口 | 保持旧 Profile 并重跑 |
| 6 | 若涉及加密与密钥约束：按双证书重叠期执行轮换预演 | ① 新旧令牌均被接受 ② 切换后旧令牌被拒 ③ 失败率与回退次数有数字 | 回退到重叠期 | 保持旧密钥可用 |
| 7 | 复核备份与驻留台账（保留期变更影响各 format 版本的独立保留策略） | 各 format 版本保留策略已更新 | 阻断收口 | 恢复旧策略 |
| 8 | 收口：记录落地时窗与证据 | ≤ 30 天 | 超期即判不合格 | — |

| A-3 | **未**要求逐域手工操作 | 是 / 否 |
