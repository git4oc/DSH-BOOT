## 2. 列定义

| # | 列名 | 类型 / 取值域 | 必填 | 语义 |
|---|---|---|---|---|
| 1 | `对象` | string | 是 | 被弃用的端点 / 语义 / 包 / 工具 / connector（**必填列 1**） |
| 2 | `垫片 id` | string（`shim-<nnn>`） | 是 | 适配层兼容垫片标识（**必填列 2**）；无垫片时填 `无（无兼容义务）` 并须评审签署 |
| 3 | `生效列车号` | string | 是 | 内核新语义/新版本开始生效的列车号（**必填列 3**） |
| 4 | `移除条件` | string（可测量表达式） | 是 | 可判定条件（**必填列 4**）；书写规则见 §4 |
| 5 | `计划移除列车号` | string | 是 | 计划移除所在列车号（**必填列 5**） |
| 6 | `status` | `planned` / `shim-active` / `ready-to-remove` / `removed` / `overdue` | 是 | 附加列 |
| 7 | `shimSwitchName` | string | 是 | 附加列。垫片开关名（**必须可独立开关**） |
| 8 | `shimSwitchDefault` | `on` / `off` | 是 | 附加列。默认值；开关状态**必须**出现在 Profile 与运行配置中并被审计 |
| 9 | `pathCallCount30d` | 整数 ≥ 0 | 是 | 附加列。该路径最近 30 天调用计数（"连续 30 天为 0"的证据） |
| 10 | `lastCallAt` | RFC3339 UTC | 是 | 附加列。最近调用时间 |
| 11 | `impactExportId` | string | 是 | 附加列。影响面与覆盖缺口导出记录 id（`EVO-034`） |
| 12 | `removalCheckId` | string | 条件必填 | 附加列。`EVO-CP-6` 校验记录 id |

## 4. 移除条件的书写规则（必须可测量）

| # | 规则 | 判定 |
|---|---|---|
| C-1 | 条件**必须**由可观测计数、静态检查结果或阈值判定构成 | 出现"观察一段时间""确认稳定"等表述即不合格 |
| C-2 | "连续 N 天调用计数为 0"的 N **必须**显式给出 | 缺少 N 即不合格 |
| C-3 | 多条件用 `且` / `或` 显式连接，**不得**用顿号罗列 | 歧义即不合格 |
| C-4 | 条件**必须**能被 CI 读取的字段引用（`pathCallCount30d`、`impactExportId` 等） | 引用了台账外不可解析字段即不合格 |
| C-5 | 至少一条条件**必须**约束影响面（`impactExportId` 无未处置条目） | 缺失即不合格 |

**可测量条件样例**：`条件成立 且 pathCallCount30d == 0（连续 30 天） 且 impactExportId 无未处置条目`

## 5. `EVO-CP-6` 弃用执行前校验 SOP

| 步骤 | 动作 | 判定 | 失败处置（回退） |
|---|---|---|---|
| 1 | 读取该条目的五列；缺任一列即停止 | 五列齐备 | 停止，**不得**执行移除 |
| 2 | 复算移除条件（计数、静态检查、影响面） | 全部成立 | **拒绝合并**；条目置 `overdue` 并告警 |
| 3 | 校验垫片开关状态已被登记并出现在 Profile 与运行配置 | 开关状态可查且有审计 | 停止 |
| 4 | 校验旧列车 Profile 与新列车 Profile 均可就绪（垫片开关 on / off 两种形态） | 双就绪通过 | 停止 |
| 5 | 执行移除；置 `status = removed`，回填 `removalCheckId` | 记录齐备 | 回退到步骤 3（保留垫片） |
| 6 | 复核 `GATE-006`：垫片状态已登记、无混版、快照 diff 为空、契约测试通过 | 全绿 | 升级未收口 |

## 6. 垫片登记与开关（`EVO-021`）

| # | 规定 | 判定 | 需求 |
|---|---|---|---|
| S-1 | 内核弃用某端点 / 语义时，**必须**先在适配层加兼容垫片 | 台账行存在且 `垫片 id != 无` | `EVO-021` |
| S-2 | 垫片**必须**可独立开关 | `shimSwitchName` 可单独置 `on` / `off` 且互不影响 | `EVO-021` |
| S-3 | 产品层**不得**直接感知内核的新语义 | 静态检查：产品壳无新语义专有标识 | `EVO-021` |
| S-4 | 垫片开关状态**必须**出现在 Profile 与运行配置中并被审计 | Profile 字段 + 运行配置 + 审计三重可查 | `EVO-021` |
| S-5 | 新列车部署后，仍引用旧语义的 Profile **必须**能通过就绪判据（由垫片承担） | 旧 Profile 就绪通过 | `EVO-021` |
| S-6 | 新 Profile **不得**依赖垫片也能就绪 | 垫片 `off` 时就绪通过 | `EVO-021` |

## 7. 过期与告警

| # | 条件 | 处置 | 需求 |
|---|---|---|---|
| A-1 | 当前列车号 ≥ `计划移除列车号` 而 `status != removed` | 置 `status = overdue` 并告警 | `EVO-022` |
| A-2 | 移除条件不成立却提交移除 | 拒绝合并 | `EVO-022` |
| A-3 | `impactExportId` 存在未处置条目 | 阻断弃用执行 | `EVO-034` |
| A-4 | 垫片开关状态未被审计 | 阻断升级收口（`GATE-006` 条件 5） | `EVO-021` |

## 8. 与影响面导出的接口（`EVO-034`）

| 字段 | 语义 |
|---|---|
| `impactExportId` | 影响面导出记录 id |
| `affectedSessions` | 仍在使用该供应商 / 该对象的活跃会话清单 |
| `affectedConnectors` | 受影响的 connector 清单 |
| `affectedProfiles` | 受影响的 Profile 清单 |
| `disposition` | 每条对象的处置路径（**必须**逐条有值） |
| `unhandledCount` | 无处置路径条目数；**> 0 即阻断弃用执行** |

**判定**：抽查 10 条受影响对象（会话 / connector / Profile），每条**必须**有目标状态与验证记录；存在一条无处置路径而弃用仍被执行即**不合格**。

## 9. 负例清单

| # | 负例 | 期望结果 |
|---|---|---|
| N-1 | 台账缺 `移除条件` 列 | CI 阻断 |
| N-2 | 移除条件写成"观察一段时间" | CI 阻断（不可测量） |
| N-3 | `pathCallCount30d != 0` 仍执行移除 | 拒绝合并 |
| N-4 | 计划移除列车号已过而未移除 | 告警并置 `overdue` |
| N-5 | 垫片开关无法独立关闭 | 拒绝发布（`EVO-021`） |
| N-6 | 旧 Profile 依赖垫片才能就绪、而新 Profile 也依赖垫片 | 拒绝（S-6 不满足） |
| N-7 | 影响面导出存在未处置条目而仍执行弃用 | **执行入口阻断** |
