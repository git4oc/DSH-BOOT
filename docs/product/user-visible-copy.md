## 1. 使用与比对规则

| # | 规则 |
|---|---|
| 1 | **比对对象 = 渲染后的纯文本**。Markdown 加粗标记 `**` 不参与比对；加粗的**强调位**由产品壳以加粗/高亮呈现，强调位不得移动、不得删除。 |
| 2 | 全角标点、括号、冒号、破折号、数字与单位、空格**必须逐字一致**。句末有无句号按本表给出的原文判定。 |
| 3 | **不得**增删语气词、不得改写为"更友好/更简洁"的措辞、不得缩略、不得翻译后回译。 |
| 4 | 出现位置为**至少**要求；同一文案在其他位置出现时仍须逐字一致。 |
| 5 | `COPY-###` 只增不改号；删除时保留编号并标 `[已废止 vX.Y]` + 理由（`SPEC-00` §4.2 同规则）。 |
| 6 | 变更流程：产品负责人 + 法务（合规类文案）+ 安全（披露类文案）会签，版本次版本 +1，并同步三处比对用例。 |
| 7 | 占位符写作 `{name}`；填充值不得含换行；占位符两侧的标点属文案本体。 |
| 8 | 工具名 / connector 名的变更**必须**走产品变更流程（`PRD-028`），默认提前 **30 天**通知客户，并提供"旧名 → 新名"映射。 |

## 2. 点名逐字文案（`SPEC-04` §3 D-1 九条）

### 2.1 `COPY-001` · `PRD-002` 跨 workspace 可见性规则

| 项 | 内容 |
|---|---|
| 出现位置（至少三处） | ① 工作区列表页**常驻**说明；② 创建/加入工作区的**确认页**；③ 产品帮助文档「工作区与可见性」条目 |
| 原文（逐字，比对基准） | 「同一个工作区里的会话可以互相看到文件；不同工作区之间，平台不保证互相看不见——需要互相看不到的人/团队，请放在不同租户或不同隔离组下。」 |
| 强调位 | 加粗：`平台不保证互相看不见`；`需要互相看不到的人/团队，请放在不同租户或不同隔离组下` |
| 附加要求 | 帮助文档同条目**必须**给出"如何申请独立租户 / 独立隔离组"的操作路径链接；产品材料全文**不得**出现 `PRD-003` / `PRD-024` 的禁用表述 |

### 2.2 `COPY-002` / `COPY-003` / `COPY-004` · `PRD-005` 移除与删除

| 文案 ID | 出现位置 | 原文（逐字，比对基准） | 交互要点 |
|---|---|---|---|
| `COPY-002` | 「移除注册」动作的**唯一**确认位 | 「移除只是把这个工作区从列表里移出，文件夹、文件和会话历史都会留在原处。」 | 强调位：`文件夹、文件和会话历史都会留在原处`；确认按钮文案为「移除注册」（**不得**写作"删除"） |
| `COPY-003` | 移除完成后的列表内提示（列表项常驻说明） | 「已移除的工作区可以重新加入；数据未被删除。」 | 与「重新加入」入口同屏；提示不得自动消失 |
| `COPY-004` | 「删除数据」动作的**二次确认**页 | 「将删除该工作区的文件、会话历史、会话记录与快照。删除将在 24 小时内生效，7 天内可以撤销。」 | 强调位：`文件、会话历史、会话记录与快照`、`24 小时内`、`7 天内`；同屏**必须**并列删除范围清单（见 `COPY-004A`） |

#### `COPY-004A` · `PRD-005` 删除范围清单（删除确认页同屏）

原文（逐字，四行并列展示，**不得**只列出其中部分）：

```
本次删除包含：
① 工作区文件（workspace 目录下的文件与附件）；
② 会话历史与会话记录（含会话事件日志）；
③ 快照；
④ 附件。
```

> 「附件」与「工作区文件」必须**分列**；`SPEC-04` 判据要求至少列出 文件 / 会话历史 / 快照 / 附件 四项。
