## 1. 范围与硬约束

| # | 约束 | 来源 |
|---|---|---|
| 1 | 审批结果的取值集**仅含** `allowed-once` / `rejected` / `cancelled` / `unavailable` / `timeout`；词表外取值即 CI 失败 | `PRD-014`；`CTR-001` §4.3 |
| 2 | 一次批准**仅作用该次调用**；**无** allow-always / 规则存储 / 撤销 | `PRD-014`；`CTR-001` §4.4 |
| 3 | 产品侧**不得**自建任何形式的"记住此工具 / 本会话内自动批准 / 信任此 connector"缓存、规则表或偏好项 | `PRD-015` |

| 9 | 审批载荷**不含参数**、不含 sessionId；面板所需上下文由审批前上报通道补齐 | `CTR-001` §4.2 |

## 2. 面板布局

### 2.1 正常态（参数已送达）

```
┌─ 审批请求 · {toolName} ────────────────────────── 剩余 {remaining} 秒 ─┐
│ 会话：{sessionName}  轮次：{turnId}  工作区：{workspaceName}           │
│ 来源：{agentLabel}（{connectorName}）  风险档位：{保守档}              │
├─ 参数预览（{usedBytes} / 8192 字节）───────────────────────────────────┤
│ 参数名                值                                             │
│ path                  /workspace/report.md                            │
│ api_key               ••••••（已脱敏）                                │
│ timeout               30                                              │
├───────────────────────────────────────────────────────────────────────┤
│ [ 仅允许这一次 ]      [ 拒绝 ]      [ 取消 ]                          │
│ 本次批准仅对该次调用有效，下次调用会重新请求确认。                     │
└───────────────────────────────────────────────────────────────────────┘
```

### 2.2 区域与字段

| 区域 | 必含字段 | 规定 |
|---|---|---|
| 头部 | `toolName`、剩余 `T_a` 倒计时 | 倒计时以秒为单位递减；到期即转为 `timeout` 态 |
| 上下文条 | `sessionName`、`turnId`、`workspaceName`、`agentLabel`、`connectorName` | 由域内应答者补齐 `(sessionId, turnId, callId)`；缺失字段显示「—」而非空白 |
| 风险档位 | `保守档` / `敏捷档` | 取值仅两项（`COPY-016`） |
| 参数预览区 | 键 → 值表；用量计数 `{usedBytes} / 8192 字节` | 见 §3 |
| 动作区 | 「仅允许这一次」「拒绝」「取消」 | 按钮文案 `COPY-015`；**不得**存在第四类按钮 |
| 页脚 | 一次性授权说明 | 逐字：「本次批准仅对该次调用有效，下次调用会重新请求确认。」 |

### 2.3 三种降级态

| 态 | 触发 | 参数区呈现 | 动作区 |
|---|---|---|---|
| **加载态** | 面板已渲染、参数预览**尚未送达** | 逐字：「参数预览尚未送达，暂不可批准。」（本基线首次拟定，须回填 `PRD-DOC-01` `COPY-028`） | 「仅允许这一次」**禁用**；「拒绝」「取消」可用 |
| **上下文缺失态** | 通道未送达 / 上报失败 / 桥未覆盖该工具 | 逐字 `COPY-006`：「上下文缺失：本次调用未提供可核验的参数，无法批准」 | 「仅允许这一次」**禁用**；**只能选择拒绝** |
| **超时态** | `T_a` 到期 | 参数区保留已展示内容并置灰 | 全部动作失效，显示 `COPY-007`：「审批已超时，本次调用未执行」 |

> 面板渲染完成前「仅允许这一次」**必须**为禁用态（`PRD-010` 判据①）：不得出现"先批准、后看参数"的路径。

## 3. 参数预览与渲染规则

### 3.1 数据来源与关联

| # | 规定 |
|---|---|
| 1 | 预览数据来自审批前上报的 `argsPreview`（含 `argsDigest`、`redacted`）；面板**不得**自行从会话事件或日志旁路读取参数 |
| 2 | 每条展示参数**必须**带 `callId`，且与 `approval.requested` 的 `callId` 一致（关联率 = 100%） |
| 3 | 同 `callId` 的 `tool.call` 事件**必须**先于 `approval.requested` 投递（定序由 `SPEC-01` 保证） |
| 4 | 断线重连后由 `GET /v1/sessions/{id}/turns/{tid}/calls/{callId}` 回补；回补前进入**加载态** |

### 3.2 脱敏（键级规则）

| 项 | 规定 |
|---|---|
| 规则形态 | **键级**规则并落入配置；配置表在版本库中以键级规则形式存在 |
| 命中判定 | 键名**不区分大小写**命中 `KEY`、`PASSWORD`、`SECRET`、`TOKEN`、`CREDENTIAL`、`COOKIE`、`AUTH` 任一**子串** |
| 命中后显示 | 值一律显示为逐字：「••••••（已脱敏）」（`COPY-013`） |
| 未命中 | 显示脱敏后原值；**不得**只显示参数名不显示值 |
| 禁止 | 不得以"名称启发式"作为控制手段；不得展示命中键的原文（含截断后的原文片段） |
| 用例集 | 逐键用例 ≥ 10 个键样例（覆盖大小写混合、子串位置在前/中/后、嵌套对象键名、数组下标内的对象键名） |

### 3.3 体积上限与截断

| 项 | 规定 |
|---|---|
| 上限 | 单次审批展示上限 **8192 字节**，为配置项 |
| 计量口径 | 按 `argsPreview` 的键值对文本序列化后的 **UTF-8 字节数**计；固定头部（工具名、会话、轮次、脱敏标记、用量计数）**不计入** |
| 截断规则 | 按上报顺序累加键值对；不切断多字节字符、不切断键值对行；单值超限时对**该值**截断（保留键名与脱敏标记） |
| 截断提示 | 面板参数区底部显示逐字 `COPY-014`：「参数过长已截断，仅展示前 8 KiB」，并显示 `已展示 {n} / 共 {m} 字节` |
| 禁止 | 不得把大文件内容整体塞入审批流；文件类参数只展示**目标路径与字节数**，不展开内容 |
| 落库 | 审批落库记录中的 `argsPreview` 不得超过上限（含固定头部后的总载荷 ≤ 上限 + 固定头部） |

### 3.4 值渲染

| 值类型 | 渲染 |
|---|---|
| 短字符串 / 数字 / 布尔 | 单行等宽显示，原样 |
| 多行字符串 | 等宽显示，最多展开 12 行，超出以 `…（已折叠 n 行）` 折叠；折叠**不改变**字节计量 |
| 目标路径 | 等宽显示绝对路径；越出 workspace 根的路径以警示色标注 |
| 结构化对象 | 缩进 JSON 形式，键序与上报一致 |
| 二进制 / 超长内容 | 仅显示 `<binary {n} bytes>` 或截断前言 |

**键序**：严格按上报顺序渲染，**不得**排序、去重或重排（便于与 `argsDigest` 人工/工具比对）。

## 4. 风险档位（仅两档）

| 项 | 保守档（默认） | 敏捷档 |
|---|---|---|
| `requireApproval` | 写类与外发类工具**进入**，逐次审批 | **空集** |
| 沙箱模式 | ≤ 租户 `sandboxModeCeiling`（部署默认 `read-only`） | **锁定 `read-only`** |
| 注册工具集 | 按 `toolAllowlist` | 只注册**零副作用**工具 |
| 交互 | 每次调用弹窗 | 发轮次前**一次前置确认**（`COPY-016A`），轮次内**无逐次弹窗** |
| 被拒表现 | — | 写类调用被拒绝并提示 `COPY-016B` |
| 禁止 | — | **禁止第三档**；不得以"自研 allow-always"实现免弹窗 |

**升权（escalation）处置**：

| # | 规定 |
|---|---|
| 1 | 面板**必须**解析 `sandbox_permissions` 与 `justification`；解析不到即 **fail-closed**（拒绝），不得因载荷无参数而盲批 |
| 2 | 请求模式**超过** `sandboxModeCeiling` 即拒绝（域外判定，不依赖域内） |
| 3 | 升权请求在面板中显式展示：逐字（本基线首次拟定，须回填 `PRD-DOC-01` `COPY-029`）：「本次调用请求将沙箱模式提升至 {mode}；理由：{justification}」 |
| 4 | `sandbox_permissions` 的请求与批准**进**最小审计集 |

## 5. 决策与状态机

```
pending ──► decided{allowed-once | rejected | cancelled | unavailable | timeout} ──► consumed
```

| UI 动作 | 决策取值 | 说明 |
|---|---|---|
| 「仅允许这一次」 | `allowed-once` | 仅该次调用有效；同一工具**下一次调用仍弹窗** |
| 「拒绝」 | `rejected` | 调用不执行 |
| 「取消」 | `cancelled` | 用户主动取消；请求被 abort 同样收敛为 `cancelled` |
| （无动作，`T_a` 到期） | `timeout` | 调用未执行；显示 `COPY-007` |
| （域外通道不可达 / 参数补全失败） | `unavailable` | fail-closed；面板显示逐字（本基线首次拟定，须回填 `COPY-030`）：「审批服务暂不可用，本次调用未执行。」 |

| # | 规定 |
|---|---|
| 1 | 关闭面板**不产生**决策；条目仍在收件箱中待决，直至 `T_a` 到期 |
| 2 | 同一 `callId` 只能被决定一次；重复提交返回已决状态并显示 `COPY-017` 后句 |
| 3 | 决策**必须**可审计：决策记不下即拒绝该动作（最小审计集） |
| 4 | 审计只写 `toolName` / `callId` / `reason` / 决策；**不得**持久化 `displayReason`（`CTR-001` §4.2） |

## 6. 全局收件箱（用户维度聚合）

| 项 | 规定 |
|---|---|
| 端点 | `GET /v1/approvals?status=pending`；决定经 `POST /v1/sessions/{id}/approvals/{aid}` |
| 聚合维度 | **用户维度**，跨会话（**不**按会话） |
| 计数对账 | 收件箱计数 == 该用户所有会话待审批数之和（**差值 0**） |
| 回写 | 从收件箱批准/拒绝后，结果**回写原会话**，原会话页状态同步更新 |
| 排序 | 默认按剩余 `T_a` 升序（最先超时者在前） |
| 筛选 | 按会话 / 工具 / connector / 风险档位 |
| 条目字段 | `toolName`、`connectorName`、`sessionName`、`workspaceName`、发起时间、剩余 `T_a`、风险档位 |
| 过期条目 | 已 `decided` 的条目保留可查但不可操作，显示 `COPY-017` 后句：「该审批已完成或已超时，无需再处理。」 |
| 多端一致性 | 同一条目在多标签页/多设备的决定结果以服务端一次性消费语义为准；后到操作不得产生第二次授权 |

## 7. 子代理边界

| # | 规定 |
|---|---|
| 1 | 启用子代理委派能力的会话页**必须**展示 `COPY-008`：「本会话内由子代理发起的工具调用不可审批：需要审批的工具在子代理内会被直接拒绝」 |
| 2 | 用户可见路径中**不得**存在子代理审批弹窗、子代理收件箱条目 |
| 3 | `requireApproval` 工具在子代理内被**硬拒**（委派时审批被钉死为 `never`）；拒绝事件可查 |
| 4 | Profile 依 `toolAllowlist` 派生子代理 `toolFilter`（实现见 `SPEC-01`） |
