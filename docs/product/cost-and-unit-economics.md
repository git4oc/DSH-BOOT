## 1. 成本公式（逐项，不得遗漏）

```
C_tenant ≈ 固定摊分(控制面 + 数据面 + 网关 + 池预热)
         + Σ_token(输入 / 输出 / 缓存命中 × 单价)        ← ★ 主成本项
         + MCP 托管(进程数 + 长连接数)
         + 存储 + 出网流量
         + Windows 域溢价(ACL 传播)
         + 支持成本
```

| # | 规定 |
|---|---|
| 1 | **推理 token 为主成本项**；**不得**以内存作为主成本锚定项。 |
| 2 | 公式项**必须**与上式逐字一致：无遗漏项、无自造项。 |
| 3 | 固定摊分的分子分母：控制面 / 数据面 / 网关 / 池预热的月成本除以**活跃租户数**；分母口径**待定**（由财务与容量工作定）。 |
| 4 | 缓存命中**必须**单列单价（与输入/输出不同价），不得并入输入。 |
| 5 | Windows 域溢价**必须**单列，覆盖 ACL 传播与独立卷；**不得**并入平台费。 |
| 6 | 温/零态压缩只影响固定摊分与存储项，**不得**用于压低 token 项。 |
| 7 | 每个画像的成本表**必须**标明取值为**假设值**或**实测值**，并标注回填计划（`PRD-044` 判据③）。 |

> 全部 `H*` 参数在 P2 出口前**必须**以「**上分位假设 + 成本加成 + 毛利护栏**」填入数字（`PRD-044` 判据③允许），并登记于 §5 假设值登记表；每项标注回填责任人。

### 2.1 毛利率计算式

```
毛利率 = ( 收入 − C_tenant ) / 收入
C_tenant 见 §1；收入 = 平台费 + 用量包计费 + 并发/域阶梯 + 存储 + 溢价 + 最低月消费达成额（− 年度折扣）
```

| # | 规定 |
|---|---|
| 1 | **≥ 3 个典型客户画像必须能算出毛利率**（P2 出口判据）；本模型覆盖 4 个画像，满足该判据。 |
| 2 | 每个画像的毛利率结果与公式取值**必须**同页呈现（画像文档三份以上）。 |
| 3 | 毛利率下限（护栏）**待定**，由**定价决策层**定；低于护栏的格**不得**按标准价出具报价。 |

## 3. 4 画像 × 3 档单位经济矩阵（`PRD-045`）

档位定义：**低 / 中 / 高**用量（按令牌用量与并发核算；档位边界值 **待定**，由定价决策层与压测工作定）。

| 画像 \ 档位 | 低 | 中 | 高 |
|---|---|---|---|
| **重度编码** | 毛利率 = `M-01`（假设值登记 `A-01`） | 毛利率 = `M-02`（`A-02`） | 毛利率 = `M-03`（`A-03`） |
| **轻度问答** | 毛利率 = `M-04`（`A-04`） | 毛利率 = `M-05`（`A-05`） | 毛利率 = `M-06`（`A-06`） |
| **MCP 密集** | 毛利率 = `M-07`（`A-07`） | 毛利率 = `M-08`（`A-08`） | 毛利率 = `M-09`（`A-09`） |
| **个人档** | 毛利率 = `M-10`（`A-10`） | 毛利率 = `M-11`（`A-11`） | 毛利率 = `M-12`（`A-12`） |

| # | 规定 |
|---|---|
| 1 | `M-01`…`M-12` **必须**全部为**数字**（无空格、无"待定"残留），在 P2 出口签署前由定价决策层按 §2 假设值算出并填入；本表给出结构与登记编号。 |
| 2 | 矩阵**必须**随成本模型变更**同步更新**并留版本号；版本号写入报价台账。 |
| 3 | 销售报价前**必须**先查该矩阵（报价流程强制步骤，见 `PRD-DOC-06` §7）。 |
| 4 | 命中"微利区间"的格：不得按标准价出具；走 §4 的产品限制或定价决策层审批。 |

## 4. 微利画像限制（`PRD-046`）

| # | 规定 |
|---|---|
| 1 | **MCP 密集画像必须单独 SKU**，不得混入企业版默认档。 |
| 2 | 该 SKU 的 **connector 数量上限**与**长连接数上限**为配置项；**默认值待定**（由容量与压测工作定）。 |
| 3 | 超限量时给出明确提示与升级路径（提示文案 **待定**，由产品负责人定）。 |
| 4 | 个人档的微利风险由**温/零态压缩**承担；若压测证明压缩不足，须按 `PRD-049` 重出矩阵并调整最低月消费。 |
| 5 | 高用量档若毛利率低于护栏，优先动作顺序：① 调整用量包单价；② 调整并发/域阶梯；③ 设定最低月消费；④ 拒绝该报价（须记录理由）。 |
