## 3. 必含声明位（逐字文本）

> 全部文本与 `PRD-DOC-01` 同源。加粗标记不参与字符串比对，标点与数字必须逐字一致。

### `S-01` 跨 workspace 可见性规则（`PRD-002` / `PRD-003` / `PRD-024`）

出现位置（`M-01`/`M-02`/`M-04`/`M-07`/`M-08`）：官网与帮助文档「工作区与可见性」条目、销售 PPT 架构页、演示话术。

```
同一个工作区里的会话可以互相看到文件；不同工作区之间，平台不保证互相看不见——需要互相看不到的人/团队，请放在不同租户或不同隔离组下。
```

**附加义务**：帮助文档同条目必须给出"如何申请独立租户 / 独立隔离组"的操作路径链接。该披露与实测一致性由 `SPEC-01` 的 `SEC-089`（读不隔离写入 DPA 与产品说明）承载；本清单只作材料面判定。

### `S-02` 租户内互信声明（`PRD-020`）

出现位置：合同附件、报价单（`M-05`）、帮助文档（`M-04`）**各一份**。

```
同一租户内部假定互信。需要互相看不到的人/团队，请放在不同租户或不同隔离组下。
```

> 该声明是**报价能力门禁**的组成部分：缺少该声明位的报价单版本**不得**出具。尽调问答库中该问题的标准答案即此句。

### `S-03` 审计能力的三要素与边界句（`PRD-026`）

出现位置：官网、销售 PPT、白皮书、SLA 附件（**必须在同一材料页内共现**）。

```
审计记录为追加型写入，哈希链可发现篡改，安全事件的权威源在域外。对账可以发现不一致，不能发现伪造。
```

**禁止**：`不可篡改`、`防篡改`、`防伪造`、`tamper-proof`、`tamper proof` 一律不得出现。

### `S-04` Windows 部署形态披露（`PRD-025`）

出现位置：合同附录（`M-06`）、报价单（`M-05`）、白皮书合规章节（`M-03`）、尽调问答库（`M-08`）。

```
Windows 档下，平台对客户本机目录的安全描述符编辑会按设计保留（包括对普通删除路径语义的改变），并会在工作区目录树中形成同用户其他低完整性进程可写可删的加宽面；该风险在 Windows 上无排除手段。客户须选择"随域销毁的独立卷"或改用 microVM 部署形态。
```

| 附加要求 | 内容 |
|---|---|
| 1 | 客户以**知情同意书**签署确认；每客户配置附录登记所选部署形态（独立卷 / microVM） |
| 2 | 客户**未选择**独立卷或 microVM 时，Windows 档报价单**不可出具** |
| 3 | 存量客户在版本发布后 **30 天**内完成告知并留档 |
| 4 | 引号样式以合同模板审定为准；引号内字符内容不得变更 |

### `S-05` 域内公网工具标注（`PRD-027`）

出现位置：功能清单、帮助文档、白皮书、演示话术。

```
域内不提供公网访问工具；公网访问仅经域外代理并施加策略、DLP 与硬审计。
```

**禁止**：`Agent 可自由访问公网`、`公网自由访问`、`可访问任意公网 URL` 等表述；演示环境不得复现"模型自行把数据发往任意公网 URL"的路径。

### `S-06` 子代理内审批不可用（`PRD-019`）

出现位置：帮助文档、演示话术、尽调问答库。

```
本会话内由子代理发起的工具调用不可审批：需要审批的工具在子代理内会被直接拒绝
```

> 句末无句号，照此比对。**不得**向用户呈现"子代理内可以审批"的交互或描述。

### `S-07` 删除与保留口径（`PRD-032`）

出现位置：隐私政策、DSR 受理页、DPA 附件。

```
覆盖：会话事件日志、附件、溢出文件、全文检索派生库、快照与对象存储版本、容器临时层、审计记录。其中审计记录按合规留存要求做假名化处理，不做物理删除，并在删除报告中单列。
```

### `S-08` 软配额与计费口径（`PRD-034` / `PRD-036` / `PRD-041`）

出现位置：合同模板、报价单、计费说明页。

```
① 超额按合同单价结算；② 结算上限为承诺额度的 1.5 倍；③ 超出上限后对超额租户按比例限速，不停止服务、不波及其他租户；④ 计费与审计各自独立缓冲，超限时有界丢弃并以 reconciled:false 墓碑标记，恢复后对账。
```

**报价单必填字段**：超额单价、上限倍数（默认 1.5 倍）；缺少任一项即不可出具。

### `S-09` 公平性承诺句（`PRD-038`）

出现位置：SLA 与产品材料。

```
平台不会把某租户的用量失控转化为其他租户的不可用。
```

## 5. 允许表述白名单（可用，但不构成更强承诺）

| # | 可用表述 | 边界 |
|---|---|---|
| 1 | `分区` / `分组` / `归属` | 仅描述组织与呈现，不得暗示隔离 |
| 2 | `租户级安全边界` | 仅可用于租户，不得用于 workspace |
| 3 | `隔离组` | 须与"同一租户内被指派到同一隔离域的工作区集合"的定义一致 |
| 4 | `容器级隔离` / `容器级边界` | 仅描述跨租户外层边界 |
| 5 | `跨租户互不可见` | 仅限**跨租户**，且须与 Windows 档披露（`S-04`）同页出现 |

> 白名单表述**不得**被用于暗示 workspace 级隔离；使用即触发 A 类复核。

## 6. 一票否决项与阻断规则

| # | 触发 | 后果 |
|---|---|---|
| 1 | 材料中出现"多人共享租户 + 工作区分隔"的 SKU 形态（`PRD-021`） | **发布阻断**；SKU 表与报价系统同步清理 |
| 2 | Windows 档客户未选择独立卷或 microVM（`PRD-025`） | 该客户报价单**不可出具** |
| 3 | 材料出现"不可篡改 / 防篡改 / 防伪造"（`PRD-026`） | **发布阻断**，须全量撤回已分发版本并重制 |
| 4 | 缺少 `S-02` 声明位的报价单版本（`PRD-020`） | 报价**不可出具** |
| 5 | 出现 allow-always 类便利功能宣传（`PRD-015`） | **发布阻断**（材料评审 + 代码审查双拦截） |
| 6 | 演示中隐式展示本期不可用能力（`PRD-058`/`PRD-059`） | 演示脚本返工，重新签署 `M-07` |

## 7. 复检频率与告知义务

| 项 | 要求 |
|---|---|
| 触发时机 | 每次对外发布、每次报价、每次版本升级后能力矩阵变更、每次 SKU 表变更 |
