## 1. 报价前置规则

| # | 规则 |
|---|---|
| 1 | **报价能力先于签约能力**：P2 出口前，产品**不得**签署含用量计价条款的合同。 |
| 2 | 报价前**必须**查阅当前版本的成本模型与 4 画像 × 3 档单位经济矩阵（`PRD-DOC-07`）；引用过期版本即不通过。 |
| 3 | 报价前**必须**完成产品材料门禁的声明位签署（`PRD-DOC-02`）：缺 `S-02` 声明位的报价单版本不可出具。 |
| 4 | Windows 档客户未选择「随域销毁的独立卷」或 microVM 时，Windows 档报价单**不可出具**。 |
| 5 | 报价单引用的成本模型版本号与矩阵版本号**必须**可追溯（写入台账）。 |

## 2. 报价单模板

### 2.1 头部字段（全部必填）

| 字段 | 说明 |
|---|---|
| 报价编号 | `QT-<YYYY>-<seq>`，全局唯一，不得复用 |
| 客户名称 / 租户 `tenantId` | `tenantId` 与合同一致 |
| 报价日期 / 有效期 | 有效期默认 **30 天**（**待定**，由销售负责人确认） |
| SKU | 企业版 / 团队版 / 个人版 / 共享域档（立项后）/ MCP 密集 SKU |
| 客户画像 | 重度编码 / 轻度问答 / MCP 密集 / 个人档 |
| 用量档位 | 3 档之一（低 / 中 / 高） |
| 矩阵版本号 | 引用 `PRD-DOC-07` 的矩阵版本 |
| 成本模型版本号 | 引用 `PRD-DOC-07` 的成本模型版本 |
| 毛利率（该格） | 取自矩阵对应格；低于毛利护栏时**不得**按标准价出具 |

### 2.2 七字段定价结构（`PRD-048`，缺一不可）

| # | 字段 | 必填 | 单位 / 取值规则 | 默认值 |
|---|---|---|---|---|
| 1 | **平台费** | 是 | 元 / 月，按租户计 | **待定**（定价决策层） |
| 2 | **用量包** | 是 | 令牌额度包（含输入/输出/缓存命中单价规则） | **待定**（定价决策层） |
| 3 | **并发 / 域阶梯** | 是 | 按并发会话数与域数分档定价 | **待定**（定价决策层） |
| 4 | **存储** | 是 | 元 / GB·月（含 workspace 文件、日志、附件、快照） | **待定**（定价决策层） |
| 5 | **Windows / 合规档溢价** | 是 | **不得为空** | **待定**（定价决策层；须覆盖 ACL 传播与独立卷成本） |
| 6 | **最低月消费** | 是 | 元 / 月，按 SKU 与画像设定 | **待定**（定价决策层） |
| 7 | **年度折扣** | 是 | 折扣率与适用条件（年付/多年） | **待定**（定价决策层） |

**附加必填**（与七字段并列，缺失即不可出具）：

| 字段 | 规则 |
|---|---|
| 超额单价 | 按计量单位给出单价；**必填** |
| 上限倍数 | **默认 1.5 倍**（结算上限 = 承诺额度 × 1.5）；**必填**，不得留空 |
| 超出上限后行为 | 「对超额租户按比例限速，不停止服务、不波及其他租户」（逐字，见 §3） |
| 不可计量用量的风险表述 | 「单月不可计量用量不超过承诺额度的 {X}%」形式；`{X}` **待定**（由定价决策层与 `SPEC-02` 共同定），须为**已度量且有上限**的表述 |

## 3. 软配额条款（合同与报价单同步，逐字）

```
① 超额按合同单价结算；② 结算上限为承诺额度的 1.5 倍；③ 超出上限后对超额租户按比例限速，不停止服务、不波及其他租户；④ 计费与审计各自独立缓冲，超限时有界丢弃并以 reconciled:false 墓碑标记，恢复后对账。
```

| # | 规定 |
|---|---|
| 1 | 该四要素**必须**写入标准合同模板，并由**法务 + 产品双签**。 |
| 2 | 报价单**必须**含「超额单价」与「上限倍数」两个字段（默认 1.5）。 |
| 3 | 用量口径**必须**与 `PRD-DOC-10` 一致：真源 = 会话事件日志 + 上传确认水位；幂等键 `(tenantId, turnId)`；对账窗口 T+24 h；数据新鲜度 **T+1**。 |
| 4 | 自助扩容：配额达 **70%** 提示（应当）、达 **80%** **必须**在控制台与会话页预警并提供**自助扩容**入口；扩容**不得**依赖人工工单。 |
| 5 | 报价材料**必须**写入"客户可自助导出全量原始用量数据用于独立复核账单"的能力（`PRD-036` / `PRD-042`）。 |

## 4. 席位列（非主变量，`PRD-047`）

| # | 规定 |
|---|---|
| 1 | **不得**以"席位数量 × 单价"作为**唯一或主**计价变量。 |
| 2 | 「席位」至多作为**次要系数**（如并发/域阶梯的辅助系数），**不得单独构成报价**；报价单中不存在"仅按席位计价"的版本。 |
| 3 | 主计价变量**必须**取自七字段的组合（平台费 / 用量包 / 并发或域阶梯 / 存储 / 档位溢价 / 最低月消费 / 年度折扣）。 |
| 4 | 抽查 **100%** 报价单通过计价变量检查；命中违规即**不得出具**。 |

## 5. 免责与声明位（报价单必含）

| 声明位 | 来源 | 内容要求 | 缺失后果 |
|---|---|---|---|
| `S-02` 租户内互信声明 | `PRD-020` | 逐字：「同一租户内部假定互信。需要互相看不到的人/团队，请放在不同租户或不同隔离组下。」 | **报价不可出具** |
| `S-04` Windows 部署形态披露 | `PRD-025` | 逐字段落全文（见 `PRD-DOC-02`）+ 客户所选形态（独立卷 / microVM）登记位 | Windows 档**报价不可出具** |
| `S-03` 审计边界句 | `PRD-026` | 「对账可以发现不一致，不能发现伪造」与三要素同页共现 | 材料评审不通过 |
| `S-05` 域内无公网工具 | `PRD-027` | 「域内不提供公网访问工具；公网访问仅经域外代理并施加策略、DLP 与硬审计。」 | 材料评审不通过 |
| `S-08` 软配额四要素 | `PRD-034` | 见 §3 | **报价不可出具** |
| `S-09` 公平性承诺句 | `PRD-038` | 「平台不会把某租户的用量失控转化为其他租户的不可用。」 | 材料评审不通过 |
| 可用性免责与赔偿口径 | `PRD-050` / `PRD-051` | 引用 SLA 定稿版本号；未定稿时按草案标注 | 不得作为签约依据 |
| 迁移禁用替代方案 | `PRD-058` | 明确"迁移禁用 + 月度维护窗口"的替代说明 | 客户告知缺失即不通过 |

**免责声明**（逐字草案，**待法务定稿**）：

```
本报价基于报价日生效的成本模型与单位经济矩阵版本；平台保留在用量档位变更、成本模型回填或合规要求变化时调整价格的权利，调整须按合同约定的通知期限提前通知。
```

## 7. 报价流程（强制步骤）

```
① 查当前阶段能力矩阵（PRD-DOC-09）→ 确认所报能力在本阶段标注为「可用」
② 查成本模型与 4×3 矩阵（PRD-DOC-07）→ 取该画像×档位格
③ 查毛利率是否低于护栏 → 低于护栏须走定价决策层审批
④ 查产品材料门禁签署（PRD-DOC-02）→ 缺声明位则停止
⑤ 生成报价单（七字段 + 附加必填）→ 台账登记
⑥ 审批与用印前检查（PRD-DOC-08）
```
