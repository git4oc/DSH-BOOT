## 3. `PRD-051` 赔偿条款定稿

| # | 要素 | 内容要求 |
|---|---|---|
| 1 | 触发条件 | 与 SLI 归因一致；区分平台责任与模型厂商责任 |
| 2 | 计算方式 | 公式 + 计量周期；示例至少一个（示例数字 **待定**，由法务与财务确认口径） |
| 3 | 申请流程 | 提交入口、所需材料、处理时限 |
| 4 | 申请时限 | 自事件发生起的申请窗口（数值 **待定**，由法务定） |

**模型厂商故障不计入平台赔偿（逐字，待法务定稿）**：

```
因模型厂商侧故障、限流或服务中断导致的中断，不计入平台赔偿；平台仍按错误预算归因规则单独披露该类中断的占比。
```

| # | 规定 |
|---|---|
| 1 | 赔偿条款与 SLA 归因表**必须一致**，任何冲突即本项不通过 |
| 2 | 赔偿计算示例随附，示例口径不得与正式条款矛盾 |
| 3 | 触发与免责规则需与 `PRD-037`（L1b 不计费争议处理）口径一致 |

## 4. `PRD-052` 维护窗口

| # | 项 | 值 / 要求 |
|---|---|---|
| 1 | 常规窗口时长 | **待定**（由 `SPEC-02` 与运维定）；须与变更批次匹配 |
| 2 | 常规窗口频率 | **待定**（由 `SPEC-02` 与运维定）；须与服务目标一并披露 |
| 3 | 提前通知时间 | **默认提前 7 天**（为可判定数值） |
| 4 | 单次最长时长 | **待定**（由 `SPEC-02` 与运维定） |
| 5 | 紧急维护判定条件 | 至少含：安全事件响应、数据完整性风险、依赖方强制升级；**须为可判定条件** |

| 7 | 客户可见状态页 | 窗口内**必须**可访问；显示**原因**与**预计恢复时间** |
| 8 | 通知记录 | 每客户每次一条，可查 |

**与 MVP 可砍项的对应**：以「同域单实例恢复 + **迁移禁用** + 月度维护窗口」替代跨实例迁移；维护窗口因此成为**合同要件**，材料与报价须如实反映（`PRD-058`）。

## 5. `PRD-053` 数据驻留声明

四项**逐字**在列：

```
① 每租户绑定驻留区域；
② 数据不出区域；
③ 跨 AZ 属"恢复"而非"重调度"（分钟到小时级）；
④ 数据面副本与备份的驻留说明随区域绑定。
```

| # | 规定 |
|---|---|
| 1 | 客户**可选**驻留区域，且选择结果可导出 |
| 2 | **不得**将跨 AZ 表述为秒级切换；跨 AZ 必须与节点故障分列（`SPEC-02` 故障域矩阵口径） |
| 3 | 备份：带外；**格式版本耦合**——跨格式版本的备份不可互读，须在声明中如实说明 |
| 4 | 数据面单副本故障导致的在途工具调用"结果未知"须有数字口径（引用 `SPEC-02`） |

## 6. `PRD-054` 租户数据导出

| # | 项 | 要求 |
|---|---|---|
| 1 | 范围 | 全量会话日志、workspace 文件、附件与清单元数据；**导出范围须与删除范围同源** |
| 2 | 格式 | 声明导出格式（结构化清单 + 原始日志与文件；格式 **待定** 由研发与产品定，须写入合同与帮助文档） |
| 3 | 单次时限 | **默认 ≤ 72 小时**；大数据量**分片**导出 |
| 4 | 交付方式 | 声明交付方式（安全下载链接 / 对象存储临时凭据等）；**待定**由研发定 |
| 5 | 完整性校验 | 导出含**完整性校验值**（如逐文件摘要 + 清单摘要），客户可校验 |
| 6 | 验收 | E2E 抽检一个租户全量导出；字段对照表通过 |

## 8. 用印流程卡点与偏离审批

| # | 卡点 | 规定 |
|---|---|---|
| 1 | 合同流程**必须**含本清单作为强制检查页；六项各有签署位与证据链接 |
| 2 | 未通过的合同**无法**进入用印流程（系统化卡点，非人工提醒） |
| 3 | 任一要件未通过时，销售侧**必须**提交书面偏离审批后由决策层批准 |

**偏离审批模板**：

| 字段 | 内容 |
|---|---|
| 偏离项 | 六项中的哪一项（含条款号） |
| 原因 | 具体业务原因 |
| 补偿 | 对客户的补偿或替代约束 |
| 风险敞口 | 对客户与平台的影响面 |
| 有效期 | 偏离有效期与复核时点 |
| 批准 | 产品负责人 / 法务 / SRE 会签 + 决策层批准 |

> 偏离**不得**用于 `PRD-050`–`PRD-055` 的**硬性事实**（如"数据不出区域"），仅可用于尚未定稿的数值与时点，并须记录复核时点。
