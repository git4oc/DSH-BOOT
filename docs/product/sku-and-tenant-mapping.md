> **术语基线（不得改写）**：**安全边界 = 租户（`tenantId`）**；**隔离组 = 同一租户内被指派到同一隔离域的工作区集合**；**workspace = 域内分区，不是安全边界**；**域内读不隔离**。

## 1. SKU 表（隔离粒度承诺）

| SKU | 安全租户 | 隔离组粒度 | 隔离实现 | 成本手段 |
|---|---|---|---|---|
| **企业版** | **每客户一个** | 默认**租户级**；need-to-know 客户可用**团队/用户级**隔离组 | **容器级隔离** | 域池三态（热/温/零） |
| **团队版** | **每团队一个** | **租户级** | **容器级隔离** | 域池三态 |
| **个人版** | **每人一个租户** | —（单用户） | 容器级隔离 | **成本由温/零态压缩承担** |
| **共享域档**（可选立项，立项后启用） | 一个**平台池租户** | **用户级** | 共享运行时（**须合同如实披露**） | 池化共享 |

**共享域档的四项强制约束（立项入口条件，逐字）**：

```
① 禁止一切带凭证能力；
② 强制 read-only；
③ 禁止跨 workspace 共享挂载；
④ 合同如实披露"共享运行时"。
```

> 未签署该四项约束清单时，报价系统中共享域档为**不可选**；该清单为立项评审的**入口条件**。共享域档是否立项与定价细节 **待定**，由**项目决策层**定（`SPEC-04` §7 第 10 项）。

## 2. `tenantId` 生成规则

| SKU | 生成规则（拟定） | 签发系统 | 可否复用 | 客户可见 |
|---|---|---|---|---|
| 企业版 | `t_c_<customerId>`，一客户一值，终身不变 | 控制面租户服务 | 否（不得复用已销毁租户的 id） | 是（合同与账单中展示） |
| 团队版 | `t_g_<teamId>`，一团队一值 | 控制面租户服务 | 否 | 是 |
| 个人版 | `t_u_<userId>`，**一人一值** | 控制面租户服务 | 否 | 是 |
| 共享域档 | `t_pool_<poolId>`，一池一值 | 控制面租户服务 | 否 | 是（并披露为共享运行时） |

| # | 规则 |
|---|---|
| 1 | `tenantId` 是**唯一安全边界**；跨租户的文件、网络、进程、依赖互不可见（Windows 档需随域销毁的独立卷或 microVM，见 §6）。 |
| 2 | 用户令牌绑定 `tenantId` 与允许的 workspaceId 集合；域令牌绑定 **`(tenantId, isolationGroupId)`**，域外校验"请求声称的租户 == 令牌中的租户"。 |
| 3 | 一个 `tenantId` **不得**承载多个自然人并依靠"域内分区"实现隔离（见 §5 一票否决）。 |
| 4 | 租户销毁后其 `tenantId` 不得复用；重新签约的客户获得新值。 |
| 5 | 租户表的**唯一真源在域外**（workspace 注册表同样域外自建），域内不得再挂一份。 |

## 3. `isolationGroupId` 生成规则

| 粒度 | 生成规则（拟定） | 适用 SKU | 域路由效果 |
|---|---|---|---|
| **租户级（默认）** | `ig_default_<tenantId>`（该租户单值） | 企业版（默认）、团队版 | 一个 `(tenantId, isolationGroupId)` 对应一个域；**一租户一域** |
| **团队级** | `ig_team_<tenantId>_<teamId>` | 企业版（need-to-know 客户） | 同一租户多域；**域内 workspace 之间仍读不隔离**，跨隔离组之间互不可见 |
| **用户级** | `ig_user_<tenantId>_<userId>` | 企业版（need-to-know 客户）、共享域档 | 同一租户多域；共享域档中每用户一个隔离组 |

| # | 规则 |
|---|---|
| 1 | **需要 need-to-know 的客户必须选团队级或用户级**——因为**域内读不隔离**（可读同域另一 workspace 的文件）。 |
| 2 | 默认"一租户一域"；一个 `(租户, 隔离组)` 对应一个容器；同一域内所有 workspace 的插件集是**并集**，工具面因此相同；有 per-workspace 裁剪需求者走**独立隔离组**。 |
| 3 | 同一域内的多个 workspace **必须**各自独立可写根、不同卷；同一 workspace 任一时刻**只被一个域可写**（带可转移租约）。 |
| 4 | 隔离组粒度**变更**（如租户级 → 团队级）等于新建隔离组并迁移 workspace；迁移期间**不得**并发写同一 workspace。 |
| 5 | 一 workspace **不得**跨隔离组共享可写挂载；只读共享工作区仅限**租户级**且 `writable:false`。 |

## 4. SKU → 建模映射表

| SKU | `tenantId` 粒度 | `isolationGroupId` 粒度 | 默认域数 | Profile 可判定字段 | 隔离承诺逐字表述 |
|---|---|---|---|---|---|
| 企业版 | 每客户 1 个 | 租户级（默认）/ 团队级 / 用户级 | 1（默认） | `sandboxModeCeiling`、`toolAllowlist`、`requireApproval`、风险档位 | 「每客户一个安全租户，容器级隔离；同一租户内部假定互信。」 |
| 团队版 | 每团队 1 个 | 租户级 | 1 | 同上 | 「每团队一个安全租户，容器级隔离；同一租户内部假定互信。」 |
| 个人版 | 每人 1 个 | — | 1 | 同上 | 「每人一个租户；成本由温/零态压缩承担。」 |
| 共享域档 | 每池 1 个 | 用户级 | 多（池内共享） | 额外强制 `read-only`、无凭证能力 | 「多客户共用一个平台池租户；合同如实披露"共享运行时"。」 |

**共同强制字段**：任何 SKU 的 Profile **必须**单一预设、`toolAllowlist` 非空、无 `plugin-manager` / `hmr` 行、`danger-full-access` 不可达。

## 5. 一票否决项（`PRD-021`）

| # | 禁止形态 | 判定方式 | 后果 |
|---|---|---|---|
| 1 | 多个自然人共用一个 `tenantId`，依靠"域内分区 / 工作区分隔"实现隔离 | SKU 表审查 + 报价系统配置快照 | **发布阻断** |
| 2 | 该形态出现在任何 SKU、报价单或产品材料中 | 材料全文检索（见 `PRD-DOC-02` E 类词表） | **发布阻断** |
| 3 | 销售侧 Q&A 未将该形态明确列为"不提供" | 尽调问答库评审 | 材料评审不通过 |

**对客标准答案（逐字）**：

```
同一租户内部假定互信。需要互相看不到的人/团队，请放在不同租户或不同隔离组下。
```

## 6. workspace 授权建模与身份生命周期

| # | 规定 |
|---|---|
| 1 | `workspaceId` 的"允许集合"在**签令牌时固化**；**每次请求校验一次租户与隔离组**（硬依赖，在网关本地完成，不进模型热路径）。 |
| 2 | 授权变更后靠**令牌刷新**生效：**停用生效时延 ≤ 5 分钟**（与令牌 TTL ≤ 5 分钟一致，不得互相矛盾）。 |
| 3 | OIDC / SAML 登录、SCIM 用户与组的创建/更新/停用可用；**停用后即时撤销会话与令牌**（`PRD-055`）。 |
| 4 | workspace 绑定 `(tenantId, workspaceId)`，域外维护；生命周期独立于会话；**移除注册不删除数据**。 |
| 5 | 只读共享工作区：`writable:false`，租户级，不突破"单一可写根"。 |
| 6 | Windows 档：域**必须**使用**随域销毁的独立卷**，**不得**落在宿主共享目录；共享场景一律改用 microVM / Hyper-V（见 `PRD-025` 披露文本）。 |
| 7 | 域内读不隔离的对客披露承载：DPA 安全附录与产品说明的披露条目由 `SPEC-01` 提供（`SEC-089`）；本表只作建模与承诺表述。 |

## 7. 微利画像限制（`PRD-046`）

| # | 规定 |
|---|---|
| 1 | **MCP 密集画像必须单独 SKU**，在 SKU 表中作为独立条目存在（不得混入企业版默认档）。 |
| 2 | 该 SKU 的 **connector 数量上限**与**长连接数上限**为配置项；**默认值待定**（由容量与压测工作给出，输入项引用 `SPEC-02` 的容量模型）。 |
| 3 | 超限量时给出**明确提示与升级路径**（提示文案 **待定**，由产品负责人定；不得只返回泛化错误码）。 |
| 4 | 报价前必查 4 画像 × 3 档单位经济矩阵（见 `PRD-DOC-07`），MCP 密集画像命中"微利"区间时不得按标准价出具。 |
