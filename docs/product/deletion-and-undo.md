## 1. 三个动作不能混（对客区分表）

| 动作 | 接口 | 用户可见按钮文案 | 确认级别 | 删除对象 | 可撤销 |
|---|---|---|---|---|---|
| **移除注册** | `POST /v1/workspaces/{id}:unregister` | 「移除注册」 | 一次确认 | **无**（仅从列表移出） | 不需要（数据未删） |
| **删除数据** | `DELETE /v1/workspaces/{id}` | 「删除工作区数据」 | **二次确认** + 7 天撤销窗口 | 该 workspace 的文件、会话历史、会话记录、快照、附件 | **7 天内可撤销** |
| **删除会话** | `DELETE /v1/sessions/{id}` | 「删除会话」 | 一次确认 | **仅**会话历史 | 不适用（不动 workspace 数据） |

**硬约束**：两个动作**必须**是两个名字、两个确认级别；移除动作的按钮文案**不得**写作"删除"。

## 2. 逐字文案（基线）

| 文案 ID | 位置 | 原文（逐字） |
|---|---|---|
| `COPY-002` | 移除动作唯一确认位 | 「移除只是把这个工作区从列表里移出，文件夹、文件和会话历史都会留在原处。」 |
| `COPY-003` | 移除后列表提示 | 「已移除的工作区可以重新加入；数据未被删除。」 |
| `COPY-004` | 删除**二次确认**页 | 「将删除该工作区的文件、会话历史、会话记录与快照。删除将在 24 小时内生效，7 天内可以撤销。」 |

**删除确认页必须同屏展示删除范围清单（至少四项）**：

```
本次删除包含：
① 工作区文件（workspace 目录下的文件与附件）；
② 会话历史与会话记录（含会话事件日志）；
③ 快照；
④ 附件。
```

## 3. 生效时延链（≤ 24 小时）

自 `DELETE` 确认起，删除链**必须**为下列四步，**每步必须**有可查询的时间戳，端到端 ≤ **24 小时**：

| 步 | 动作 | 时间戳字段 | 说明 |
|---|---|---|---|
| 0 | 停写（取锁）+ 二次确认 | `confirmedAt` | 停写避免与迁移竞争 |
| 1 | **墓碑** | `tombstonedAt` | 记录进入删除流程；撤销窗口内不执行下述物理擦除 |
| 2 | **域卷标记** | `volumeMarkedAt` | 标记域卷待回收 |
| 3 | **对象存储生命周期** | `lifecycleAppliedAt` | 含对象存储版本与快照 |
| 4 | **域回收时物理擦除** | `purgedAt` | 容器临时层随域销毁 |

| # | 规定 |
|---|---|
| 1 | 对上声明（逐字，本基线首次拟定）：**「删除将在 24 小时内生效，7 天内可以撤销。」**（已并入 `COPY-004`） |
| 2 | 撤销窗口内**不执行**第 4 步；撤销后工作区**必须**可恢复到**可写**状态 |
| 3 | 删除报告含四步各自时间戳，抽检执行 |
| 4 | 会话级删除（`DELETE /v1/sessions/{id}`）不走本链的域卷与物理擦除步骤，仅删除会话历史 |

## 4. 撤销窗口（7 天）

| 项 | 规定 |
|---|---|
| 窗口值 | **7 × 24 小时**，自 `DELETE` 确认起；为配置项 |
| 撤销入口 | ① 删除完成提示内的「撤销删除」；② 工作区列表的"最近删除"区（窗口内常驻）；③ 帮助文档说明页链接 |
| 撤销效果 | 文件、会话历史、快照恢复可读；工作区恢复**可写**状态 |
| 第 8 天 | 撤销入口关闭；撤销请求被拒绝并给出明确原因，逐字（本基线首次拟定）：「该工作区已超过 7 天撤销窗口，无法撤销；如需恢复请联系支持。」 |
| 时间旅行用例 | **窗口内**（第 1 天）/ **边界**（第 7 天临界前后各 1 小时）/ **超窗**（第 8 天）三类，各类须有 UI 快照与接口断言 |
| 边界处理 | 窗口以服务端记录的 `tombstonedAt` 为准；客户端时钟不得作为判据 |

## 5. 删除报告（可出具且可核验）

### 5.1 字段

| 字段 | 内容 |
|---|---|
| 删除清单 | 覆盖：会话事件日志、附件、溢出文件、FTS 派生库、快照与对象存储版本、容器临时层、审计记录 |
| 墓碑 | 墓碑标识与时间戳 |
| 删除报告本身 | 报告编号、生成时间、操作者、请求来源 |
| 哈希链证明 | 证明链与校验手段（客户侧可独立校验） |

### 5.2 状态分类（逐类必填，**不得**出现"未列出"类）

| 状态取值 | 含义 | 允许用于 |
|---|---|---|
| `已删除` | 数据已物理删除或按平台销毁链消除 | 会话事件日志、附件、溢出文件、FTS 派生库、快照与对象存储版本、容器临时层 |
| `已假名化` | 依合规留存要求做假名化处理，不做物理删除 | **审计记录**（必选值之一） |
| `保留` | 依法律或合规义务保留 | **审计记录**（必选值之一） |

> **硬约束**：审计记录行的状态**必须**为「已假名化」或「保留」，**不得**为「已删除」。

### 5.3 客户侧独立校验

| 步 | 内容 |
|---|---|
| 1 | 报告随附哈希链证明与校验步骤说明（或校验工具） |
| 2 | 客户按说明复算并比对链首/链尾摘要 |
| 3 | 校验不通过时按支持流程上报；平台侧不得要求客户"信任平台自报" |

## 6. DSR 删除范围对外口径（逐字）

出现位置：**DSR 受理页**与**隐私政策**（另见 `PRD-DOC-02` `S-07`）。

```
覆盖：会话事件日志、附件、溢出文件、全文检索派生库、快照与对象存储版本、容器临时层、审计记录。其中审计记录按合规留存要求做假名化处理，不做物理删除，并在删除报告中单列。
```

| 项 | 规定 |
|---|---|
| 尽调标准答案 | 客户问询"审计是否删除"时，标准答案即上述逐字文本 |
| 报告一致性 | DSR 受理后出具的报告中，审计行为「假名化」 |
| 计费/审计所需聚合 | 删除前先抽出所需**假名化聚合**（解决与真源模型的冲突），该聚合不得含可直接识别到自然人的字段 |

## 8. 对客 FAQ（一页通正文）

| # | 问题 | 回答（对客口径） |
|---|---|---|
| 1 | 「移除」后数据还在吗？ | 在。移除只是把这个工作区从列表里移出，文件夹、文件和会话历史都会留在原处；可以重新加入。 |
| 2 | 删除后多久彻底消失？ | 自确认起 **24 小时内**完成删除链；每步都有可查询的时间戳，删除报告可出具。 |
| 3 | 删除后能反悔吗？ | 可以。**7 天内**可在"最近删除"撤销，撤销后文件、会话历史与快照恢复，工作区回到可写状态。 |
| 4 | 第 8 天还能恢复吗？ | 不能。撤销入口关闭，撤销请求被拒绝；如需恢复请联系支持。 |
| 5 | 审计记录为什么不删？ | 审计记录按合规留存要求做**假名化**处理，不做物理删除，并在删除报告中**单列**。 |
| 6 | 快照和附件算不算在内？ | 算。删除范围含工作区文件、会话历史与会话记录、快照、附件。 |
| 7 | 删除会影响同租户其他人的工作区吗？ | 不会。删除只作用于被确认的那一个工作区；同租户其他 workspace 不受影响。 |
| 8 | 删除报告能自己验证吗？ | 能。报告随附哈希链证明与校验步骤/工具，客户侧可独立校验。 |

> FAQ 措辞**不得**超出本文件事实；不得出现"审计不可篡改""数据已彻底不可恢复地销毁于所有介质"等超范围表述。

## 9. 验收与抽检

| 项 | 判据 |
|---|---|
| 时延 | 端到端实测（含对象存储版本与快照）从确认到全部步骤完成 ≤ **24 h** |
| 撤销 | 窗口内 / 边界 / 超窗三类用例通过；撤销后工作区可写 |
| 报告 | 每类数据逐行有状态、无"未列出"类；审计行为「假名化」或「保留」；哈希链可独立校验 |
| 口径 | DSR 受理页与隐私政策含逐字文本；四个入口链接同一说明页 |
| 归口 | `GATE-005` 第 2 条（DSR 可出具删除报告）；删除报告抽检 |
