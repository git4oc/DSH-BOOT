## 1. mTLS 与 TLS 1.3 基线（`SEC-099`）

### 1.1 链路基线表（逐链路判定）

| # | 链路 | 协议要求 | 身份校验 | 证书来源 | 失败语义 |
|---|---|---|---|---|---|
| L-1 | 域 → 反向网关 | mTLS | 双向：域验网关、网关验域 | 域外签发的域证书（绑定 `(tenantId, isolationGroupId)`） | fail-closed，中断轮次（L3） |
| L-2 | 域 → 凭证代理 | mTLS | 双向 | 同上 | fail-closed，凭证不签发 |
| L-3 | 域 → MCP 出站代理 | mTLS | 双向 | 同上 | fail-closed，出站不放行 |
| L-4 | 控制面 → 数据面 | mTLS | 双向 | 服务网格证书 | fail-closed |
| L-5 | 域外组件 → 持久层（对象存储/元数据库/WORM） | TLS 1.3（或云私网 + 静态加密双保险） | 服务端校验 + IAM/凭据 | 托管 | fail-closed |
| L-6 | 产品壳/客户 → OpenAPI 网关 | **TLS 1.3 及以上**（不接受低于 1.3 的协商） | 服务端证书 + 客户令牌 | 托管证书 | 拒绝协商 |
| L-7 | 数据面 → 上游 MCP/模型网关 | TLS 1.3 | 服务端校验 | 托管/客户 | fail-closed |

### 1.2 参数基线（固定值）

| 项 | 取值 |
|---|---|
| 最低协议版本 | 对外 `TLSv1.3`；域内外 mTLS 亦 `TLSv1.3` |
| 允许的密码套件（TLS 1.3） | `TLS_AES_128_GCM_SHA256`、`TLS_AES_256_GCM_SHA384`、`TLS_CHACHA20_POLY1305_SHA256` |
| 禁止 | `TLSv1.0`/`TLSv1.1`/`TLSv1.2` 协商；`NULL`/`RC4`/`3DES`/`EXPORT` 套件；重协商；会话票证跨区域复用 |
| 证书链 | 完整链下发；禁止自签（内部 PKI 除外，且必须被域外 CA 交叉签发） |
| 客户端证书吊销 | OCSP/CRL 校验开启；吊销后 ≤ 5 min 生效 |
| HSTS（对外端点响应头，逐字） | `Strict-Transport-Security: max-age=31536000; includeSubDomains` |
| 证书有效期上限 | ≤ 397 天 |
| 轮换重叠期 | 由 `SPEC-05` 规定；重叠期内新旧证书各自签发的令牌均被接受 |

### 1.3 判定（扫描脚本必须输出）

```
{link: "L-6", negotiatedVersion: "TLSv1.3", cipher: "...", clientCertVerified: true|n/a,
 hstsHeader: "max-age=31536000; includeSubDomains", verdict: "pass|fail"}
```

- 逐链路一行；`negotiatedVersion < TLSv1.3`（对外）或 mTLS 未双向校验 ⇒ `fail`。
- 对外端点扫描**必须**包含"尝试以 TLS 1.2 协商"的负向用例，期望被拒。

## 2. 四类静态加密（`SEC-100`）

| # | 存储 | 加密方式 | 密钥归属 | 判定 | 不接受项 |
|---|---|---|---|---|---|
| S-1 | 域卷（会话日志、workspace、附件、spill、FTS 派生库） | 卷级加密 AES-256-XTS（或云盘加密 + 卷级双层） | 域外 KMS 托管 KEK；DEK 不落域 | 直接读底层块设备/卷文件为密文；域内无密钥 | 明文卷；密钥在域内 |
| S-2 | 对象存储（日志副本、快照、版本） | SSE-KMS（客户托管密钥） | 域外 KMS | 关闭 SSE 或使用平台默认密钥 ⇒ 不通过 | SSE-S3 默认密钥；桶级无加密 |
| S-3 | 元数据库（会话索引、workspace 注册表、配额账本） | 存储级加密 + 关键列应用层加密（§3） | 域外 KMS/HSM | 存储加密开启；关键列密文 | 明文列 |
| S-4 | WORM 审计 | 存储级加密 + 链段签名（`SEC-DOC-07` §6） | 域外密钥库/HSM；签名密钥不落域 | 审计对象为密文；签名可验 | 明文审计对象 |

**统一判定**：四类存储的加密配置**全部开启**且密钥**全部**由域外 KMS/HSM 持有；从域内尝试读取密钥**必须失败**（`SEC-100` 判据）。

## 3. 字段级加密与密钥分离（`SEC-101`）

| 项 | 规定 |
|---|---|
| 加密对象（字段封闭集） | ① 凭证值与其元数据（`credentialRef` 指向的实际材料、令牌明文不入库）；② 个人信息字段：`userEmail`、`userName`、`phone`、`subjectId`、`externalSubjectId`、`displayName`、`ip`（若记录）；③ `argsPreview` 中未脱敏且被判为高熵的值（`SEC-DOC-06` §2 规则 5 已替换，落库前仍须字段级加密） |
| 算法 | AES-256-GCM；每条记录独立 nonce（96 bit，随机）；禁止 nonce 复用 |
| AAD（附加认证数据，固定） | `tenantId ‖ 0x1F ‖ table ‖ 0x1F ‖ column ‖ 0x1F ‖ rowId` |
| 密钥分离 | KEK 在域外 KMS/HSM；每租户独立 DEK；DEK 由 KEK 包裹后存储；**数据与密钥分离**：任何存储快照单独泄露不足以解密 |
| 判定 | ① 直接读取元数据库/对象存储对应字段的**原始字节**为密文；② 在无密钥库访问权的环境尝试解密 ⇒ 失败；③ 抽样断言 nonce 无重复 |
| 禁止 | 应用层加密使用全局单一密钥；把 DEK 明文写入应用配置文件；在日志/审计中记录明文 PII |

## 4. 驻留区域绑定（`SEC-102`）

| 项 | 规定 |
|---|---|
| 绑定粒度 | 每 `tenantId` 绑定**一个** `residencyRegion`（见 §7 冲突项） |
| 受限数据类（封闭） | ① 会话事件日志；② workspace 数据（含附件、spill、FTS 派生库）；③ 快照与对象存储版本；④ 审计记录 |
| 判定输入（域外） | 域外区域策略 + 存储路由配置 + 副本清单（**不得**用域内上报） |
| 判定谓词 | 四类数据的**全部副本**（含快照与备份）所在区域 == 绑定区域；出现跨区副本且未登记 ⇒ 不通过 |
| 默认值 | 跨区复制**默认关闭** |
| 违规处置 | 出现跨区副本且未登记 ⇒ 拒绝 ready / 触发安全事件；已登记 ⇒ 按 §5 台账核对 |
| 硬约束 | 不得依赖"域内自证不出区域"；证明来自域外存储路由与副本枚举 |
| `SEC-*` | `SEC-102`；对接 `SPEC-05` `EVO-026` 的驻留证明完整性要求 |

## 5. 跨区登记台账（`SEC-103`）

**默认关闭**：任何跨区复制必须先有台账条目，后开配置；顺序颠倒 ⇒ 不通过。

> **分工**：台账的**载体、序列化与驻留证明导出模板**由 `EVO-DOC-10`（`docs/evolution/region-residency-ledger.md`，`EVO-026`/`EVO-031`）承载；本文件只规定**安全侧必填字段与判定**。两者字段不一致时，以本文件的安全判定字段为**下限**（不得删减），并按 `SEC-00` §8 同步。

| # | 字段 | 必填 | 判定 |
|---|---|---|---|
| X-01 | `registrationId` | 是 | 唯一，形如 `XREG-<tenantId>-<seq>` |
| X-02 | `tenantId` | 是 | — |
| X-03 | `sourceRegion` / `destinationRegion` | 是 | 区域标识（非"区域组"） |
| X-04 | `dataClasses[]` | 是 | 取 §4 四类之一或多；不得为 `*` |
| X-05 | `legalBasis` | 是 | 法规/客户书面授权/合同条款引用；不得为空泛描述 |
| X-06 | `owner` | 是 | 责任人（姓名 + 角色） |
| X-07 | `effectiveFrom` / `reviewAt` | 是 | `reviewAt` ≤ `effectiveFrom + 12 个月` |
| X-08 | `encryptionOverlap` | 是 | 目的地区域的密钥归属（必须为域外 KMS/HSM） |
| X-09 | `deletionCoverage` | 是 | 该副本是否纳入 `SEC-DOC-09` 的逐副本删除报告（**必须为是**） |
| X-10 | `configDigest` | 是 | 配置项摘要，用于与台账逐项比对 |
| X-11 | `approvedBy` | 是 | 安全 + 法务双签 |

**核对规则**：配置中的每个跨区副本必须能一对一映射到台账条目；台账条目必须能在配置中找到；双向差集为空（`SEC-103` 判据）。

## 6. 驻留与删除的证明义务（`SEC-104`）

| 要求 | 判定 |
|---|---|
| 删除报告按副本标注区域 | `SEC-DOC-09` §3.1 的 `replicas[].region` 必填；缺区域标识 ⇒ 报告不通过 |
| 覆盖跨区副本 | 存在跨区副本时，报告必须逐副本列出删除时间与校验值 |
| 覆盖带外备份 | 各 format 版本的带外备份副本必须进清单（`SPEC-05` `EVO-031`）；本文件要求其包含 `region` 字段 |
| 区域分布报表 | 能按租户列出所有数据副本所在区域；出现未登记跨区副本 ⇒ 不合格 |

## 7. 基线核对表（发布前逐行执行）

| # | 核对项 | 命令/输入 | 通过判据 | `SEC-*` |
|---|---|---|---|---|
| K-1 | 对外 TLS 版本 | 对网关执行 TLS 扫描 + 强制 TLS1.2 负向用例 | 仅 1.3；负向被拒；HSTS 头逐字匹配 | `SEC-099` |
| K-2 | 域内外 mTLS | 逐链路抓取双向证书 | 全部双向校验通过 | `SEC-099` |
| K-3 | 四类静态加密 | 读存储配置 + 读原始字节 | 四类均加密；原始字节为密文 | `SEC-100` |
| K-4 | 密钥归属 | 域内读密钥尝试 + KMS 访问审计 | 域内读取失败；密钥在域外 KMS/HSM | `SEC-100` |
| K-5 | 字段级加密 | 抽样读 PII/凭证字段原始字节；无密钥解密 | 密文；无密钥失败；nonce 无重复 | `SEC-101` |
| K-6 | 区域绑定 | 副本枚举 + 区域策略 | 四类数据全部副本在同一区域 | `SEC-102` |
| K-7 | 跨区台账 | 配置 ↔ 台账双向差集 | 差集为空；默认关闭 | `SEC-103` |
| K-8 | 删除报告区域标注 | 对含跨区副本租户执行 DSR | 逐副本含 `region` | `SEC-104` |
| K-9 | 证书有效期与吊销 | 证书台账 + OCSP 抽查 | ≤ 397 天；吊销 ≤ 5 min 生效 | `SEC-099` |
