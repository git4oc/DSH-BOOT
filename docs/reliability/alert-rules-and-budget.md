## 1. 告警模型

### 1.1 严重级别（封闭枚举）

| 级别 | 语义 | 值班动作 | 容许降级 |
|---|---|---|---|
| `hard` | 硬告警：与安全 / 合规 / 计量边界或可用性预算直接相关 | 立即 page；15 min 内响应 | **不得**降级为 `notice`（`REL-124`） |
| `notice` | 通知：趋势、可容忍偏离、容量预警 | 工单；下一工作日处理 | — |

### 1.2 载荷 schema（`REL-125`：缺字段的告警**不得发出**）

| 字段 | 类型 | 必填 | 取值 / 说明 |
|---|---|---|---|
| `tenantId` | string | 是 | 租户 |
| `isolationGroupId` | string | 是 | 隔离组 |
| `workspaceId` | string | 条件必填 | 维度为 workspace 相关软依赖 / 租约时必须 |
| `scope` | string | 是 | `domain:{domainId}` 或 `global`（与 `REL-DOC-04` §1.2 同源） |
| `dimension` | enum | 是 | `DIM-01`…`DIM-07`（`REL-DOC-04` §1.3） |
| `subKey` | string | 条件必填 | `dimension=审计` 时必填（`kind ∈ {audit, billing}`） |
| `level` | enum `L0`…`L3` / `n/a` | 是 | 降级级别；非降级类告警填 `n/a` |
| `sloId` | string | 是 | 受影响 SLO（`SLO-xx`）；非 SLO 类填 `infra:{ruleId}` |
| `window` | object `{from, to, resolution}` | 是 | 观测窗口；`resolution ∈ {1m, 5m, 1h}` |
| `ruleId` | string `^ALR-\d{2}$` | 是 | 触发规则 |
| `severity` | enum `hard` / `notice` | 是 | 见 §1.1 |
| `firstSeenAt` / `lastSeenAt` | 时间戳 | 是 | 首见 / 末见 |
| `reasonCode` | string | 条件必填 | 降级 / 迁移 / 拒绝类必填 |
| `textId` | string | 条件必填 | 需要客户可见文案时必填（引用 `PRD-*` 的文案标识，不复制措辞） |

| 校验 | 要求 |
|---|---|
| 发送前置 | 发送侧必须做 schema 校验（**不是**事后补字段）；缺任必填字段即**拒绝发送**并计 `alert.payload.invalid.count` |
| 措辞 | 载荷**不得**包含参数原文 / 凭证 / 会话内容 |

### 1.3 聚合键与去抖（`REL-121`）

| 项 | 规则 |
|---|---|
| 聚合键 | `(tenantId, dimension, subKey, level, ruleId)` —— 同一键的事件聚合为**一条**告警 |
| 进入去抖 | 只在跨过驻留阈值后触发：进入需**连续 3 次探测失败或持续 ≥30 s**（与 `REL-DOC-04` §3.1 同源） |
| 退出去抖 | 退出需 **5 min** 稳定；退出前不得重复告警 |
| 禁止 | 不得对单次探测失败告警 |
| 校验 | 注入 1000 个域同时经历 10 s 依赖抖动 ⇒ 告警条数 ≤ 1 条 / 租户 / 维度；出现逐探测告警即失败 |
| 抑制 | 同一聚合键在驻留期内的重复触发只更新 `lastSeenAt`，不新增告警 |

| 校验 | 判据 |
|---|---|
| 覆盖率 | `SPEC-02` 中每条要求告警的条款必须映射到 ≥1 条规则（`REL-050`、`REL-124` 两项为必查） |

## 4. 错误预算政策（`REL-122` / `REL-123`）

### 4.1 预算与计算式（口径沿用 `REL-DOC-01` §3.1，**不得**另立）

| SLO | 目标 | 预算计算式 | 30 天窗口数值（推导） |
|---|---|---|---|
| `SLO-01` 控制面可用性 | 99.9% | `(1 − 0.999) × 分母` | `0.1% × 43,200 min = 43.2 min/月` |
| `SLO-04` 轮次成功率 | 99.5% | `0.5% × 分母` | `0.5% × 月轮次数` |
| `SLO-13` 最小审计集可用性 | 99.99% | `0.01% × 分母` | `0.01% × 43,200 min = 4.32 min/月` |
| `SLO-12` 审计落库时延 | P95 ≤ 5 s | `5% × 分母` | `5% × 月审计事件数` |
| `SLO-03` 端到端首 token | P95 ≤ 3 s | `5% × 分母`（归因 = 模型） | 不消耗平台预算 |
| `SLO-14` 对账差异率 | ≤ 0.01% | `0.01% × 月流水`，**少计 / 多计各一份** | 分方向分账 |
| `SLO-09` 跨节点 RPO | P99 ≤ `PP-06` | `1% × 分母` | — |
| 计数型（`SLO-16`、`SLO-19`、`SLO-22`、`SLO-10` 的 `FAILED`） | 0 | 预算 = 0；任一次即消耗并触发硬告警 | — |

### 4.2 消耗 ≥ 50% 的预警动作

| 动作 | 内容 | 责任 |
|---|---|---|
| 通告 | 向平台 + 产品通告该 `sloId` 的消耗曲线与归因分列 | SRE 值班 |
| 变更收紧 | 该 SLO 相关路径的变更进入**加签**（需 SRE 会签方可合并） | 发布流水线 |
| 演练加密 | 相关演练用例（`REL-DOC-11` §7 映射）重跑频率提升至每周 | SRE |
| 归因核查 | 核查是否存在责任方归因错误或重复计数（`REL-002`、`REL-026`） | SRE |

### 4.3 消耗 ≥ 100% 的冻结清单（逐项，`REL-122`(c)）

| # | 被冻结的变更类型 | 冻结范围 | 拦截点 |
|---|---|---|---|
| 1 | **内核升级**（版本列车整列同升） | 该 SLO 相关域全部 | 流水线预算门禁（preventive，拒绝） |
| 2 | **Profile 变更** | `deadlines` / `buffers` / `toolAllowlist` / `connectors` / `sandboxMode*` 任一项 | 同上 |
| 3 | **新租户接入** | 该 SLO 覆盖的 SKU 与区域 | 同上 |
| 4 | **容量参数调整** | `PP-21`、`PP-22`、`PP-25`、`PP-31`、`PP-33` | 同上 |
| 5 | **降级阶梯阈值变更** | 进入 / 退出阈值、最短驻留 | 同上 |
| 6 | **缓冲参数变更** | `retainHours`、`PP-28`、`PP-13`、`PP-14` | 同上 |
| 7 | **SLO 目标放宽** | 该 `sloId` 的目标值 | 同上（须走 `SPEC-02` 变更控制） |
| 8 | **演练豁免** | 任何「跳过演练进灰度」的请求 | 同上（不得以豁免绕过） |
| 9 | **新增 connector** | 该租户 / 场景 | 同上 |

> 冻结**不**阻断：故障修复、回滚、扩容（受 §4.4 配额约束）、以及为解除冻结所需的变更（须 §4.3 会签记录）。

### 4.4 分账与不得挪用（`REL-123`）

| 规则 | 内容 | 拦截点 |
|---|---|---|
| 按 SLO 分列 | 预算按 `sloId` 独立记账 | 预算记账器（按 SLO 分账） |
| 按归因分列 | 平台 / 模型 / 依赖三本账；模型责任失败不消耗平台预算 | `REL-026` |
| 不得挪用 | 不得跨 `sloId` 挪用或抵扣；检索到抵扣路径即失败 | 记账器审计 |
| 不得豁免 | 冻结期不得以「新租户试运行」「POC」名义绕过 | 流水线 + 会签记录 |
| 报表 | 预算报表必须按 `sloId` 与归因分列，并可与可用性 / 降级级别同轴对齐 | `REL-127` |

### 4.5 解冻条件（`REL-122`(d)）

| # | 条件 | 证据 |
|---|---|---|
| 1 | 消耗回落至 **< 100%**，且 **≥7 天**无新增同因消耗 | 预算曲线 + 归因记录 |
| 2 | 根因已定位并修复（含变更记录与回归验证） | 复盘报告 + 回归结果 |
| 3 | 相关演练用例重跑通过（按 `REL-DOC-11` §7 映射） | 演练报告（七项字段齐备） |
| 4 | 冻结期的豁免与例外逐条复核并关闭 | 会签记录 |
| 5 | 解冻须 SRE + 产品**双签**；解冻不改变 SLO 目标 | 签署记录 |

## 5. 统计口径与时间轴

### 5.1 降级期样本（`REL-126`）

| 规则 | 内容 | 拦截点 |
|---|---|---|
| 必须计入 | 降级期（`L1` / `L1b` / `L2` / `L3`）样本**必须**计入 P95 / P99 与可用率统计 | SLO 计算管道（**禁止**按级别过滤样本） |
| 禁止排除 | 不得以「降级期」为由剔除样本 | 管道代码审查 + 注入用例 |
| 单列 | 报表必须**单列**降级期分布（按级别切片） | 报表分组 schema |
| 注入判据 | L1b 持续 1 h ⇒ 该时段时延样本出现在 P95 中；被排除即失败 | `DRL-E01`、`DRL-E22` |

### 5.2 时间轴与窗口对齐（`REL-127`）

| 规则 | 内容 | 校验 |
|---|---|---|
| 同钟源 | 可用性、错误预算、降级级别三条曲线必须同钟源 | 取任一 1 h 窗口比对刻度与边界 |
| 同窗口定义 | 窗口（5 min / 1 h / 30 天）定义唯一，三处引用同一注册表项 | 报表 schema + 观测平台配置 |
| 对齐判据 | 三条曲线的时间轴刻度与窗口边界完全一致；出现不同窗口定义导致无法对账即失败 | 自动化对齐检查 |
| 与审计时延 | `SLO-12` 的跨钟比对必须带 `PP-07` 偏差上界；超界样本单列 | `REL-017`、`REL-126` |

## 6. 校验与门禁

| 项 | 判据 | 拦截点 |
