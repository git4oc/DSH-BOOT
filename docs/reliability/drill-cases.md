## 1. 用例 schema（`REL-111`：四要素齐备）

| 字段 | 必填 | 说明 | 校验 |
|---|---|---|---|
| `drillId` | 是 | `DRL-01`…`DRL-06` / `DRL-E01`…`DRL-E24` / `DRL-X01`…`DRL-X02` | 唯一；被其他文件引用者不得改名 |

## 4. 演练报告工件（`REL-118` 七项字段）

| # | 字段 | 类型 | 必填 | 说明 | 校验 |
|---|---|---|---|---|---|
| 1 | `drillId` | string | 是 | 用例号 | 必须解析到 §2/§3 的用例 |
| 2 | `executedAt` | 时间戳（含时区） | 是 | 执行时刻 | 非空 |
| 3 | `environment` | object `{envId, topologyDigest, platform[], trainVersion}` | 是 | 环境标识与拓扑清单 | `envId` 必须为 §5 的预发环境标识 |
| 4 | `injectionParams` | object | 是 | 注入参数（含旋钮取值、持续时长、次数） | 非空且可复算 |
| 5 | `observations` | array（原始数据或可复算的查询引用） | 是 | 观测指标原始数据 | 必须可复算；仅结论不合格 |
| 6 | `result` | enum `pass` / `fail` | 是 | 通过 / 失败 | 逐条对应 `passCriteria` 编号 |
| 7 | `deviations` | array `{item, declared, measured, delta, verdict}` | 是（可为空数组） | 偏差项（尤其矩阵声明 vs 实测） | 超差即矩阵失效并复审 |

| 附加要求 | 内容 |
|---|---|
| 存档 | 报告必须存为可审计工件（写入即不可改；修订以新版本追加） |
| 缺项后果 | 缺任一必填字段 ⇒ 该次演练**不构成**门禁证据（视为未演练） |
| 关联 | 必须关联 PR 或发布批次号，供灰度门禁检索 |
| 可视化检查 | 涉及用户可见行为的用例（`DRL-01`、`DRL-03`）必须附截图或录像引用（`PRD-006`、`PRD-009`） |

## 5. 环境要求（`REL-120`）

| 项 | 要求 | 校验 |
|---|---|---|
