## 1. 登记表 schema（`REL-001` / `REL-003`）

### 1.1 字段定义

| 字段 | 类型 | 必填 | 校验点 | 说明 |
|---|---|---|---|---|
| `sloId` | string `^SLO-\d{2}[a-z]?$` | 是 | CI：登记表 schema | 条目号 |
| `name` | string | 是 | CI | 指标名 |
| `target` | string（含数值与分位） | 是 | CI：正则须含数字 | 目标；无数值即失败 |
| `numerator` | string | 是 | CI：非空 | 分子 |
| `denominator` | string | 是 | CI：非空 + **分母去重键** | 分母 |
| `denominatorKey` | string | 是 | CI：`denominatorKey` 全局唯一 | 与 `REL-003` 对应：两条 SLO 同键即失败 |
| `measurePoint` | string | 是 | CI：非空 | 测量点（须可定位到 span / 事件 / 计时器） |
| `exclusions` | string[] | 是（可为空数组，但字段必须存在） | CI：字段存在性 | 排除项；空数组 ≠ 缺字段 |
| `attribution` | enum `平台` / `模型` / `依赖` | 是 | CI：枚举 | 归因 |
| `dataSource` | string[] | 是 | CI：非空，每项须为已登记系统 | 数据来源系统 |
| `budgetOwner` | enum `平台` / `模型` / `依赖` | 是 | CI：必须 == `attribution` | 错误预算归属（`REL-026`） |
| `budgetFormula` | string | 是 | CI：含分位或比例 | 预算计算式（见 §3.1） |
| `relIds` | string[] `^REL-\d{3}$` | 是 | CI：ID 可解析 | 落实的需求 ID |
| `phase` | enum `P0`–`P4` | 是 | CI | 首次可判定阶段 |
| `status` | enum `可判定` / `待回填` | 是 | CI：`待回填` 时 `pendingParams` 非空 | — |
| `pendingParams` | string[] `^PP-\d{2}$` | 条件必填 | CI：ID 须存在于 `REL-DOC-02` | 阻塞该项判定的待回填参数 |

### 1.2 完整性校验（`REL-001` 的拦截点）

1. CI 任务 `slo:registry` 按 §1.1 逐字段校验；**缺任一必填字段即失败**。
2. 同一 `denominatorKey` 出现 ≥2 次即失败（`REL-003`：可用性与网关可用性不得分列计数）。
3. 发布前抽 3 条 SLO 在预发按登记口径复算，复算值与登记值偏差须 ≤ 该指标测量误差容许带（登记表内 `measureTolerance` 字段显式给出，缺省 = 目标值的 5%）。
4. `status = 待回填` 的条目**不得**写入对外 SLA 数值位（`PRD-050` 已要求 SLA 不得含占位符）。

## 3. 错误预算归属与记账（`REL-026` / `REL-123` / `REL-122`）

### 3.1 预算计算式（统一推导，禁止逐条另立）

| 目标类型 | 预算公式 | 推导 |
|---|---|---|
| 可用率（`x%`） | `预算 = (1 − x%) × 分母样本数` | 30 天 = 43,200 min；99.9% ⇒ 0.1% × 43,200 = **43.2 min/月**；99.99% ⇒ 0.01% × 43,200 = **4.32 min/月** |
| 分位（P95） | `预算 = 5% × 分母样本数` | P95 的合格定义即「≤95% 样本达标」⇒ 允许超阈样本比例 = 100% − 95% = 5% |
| 分位（P99） | `预算 = 1% × 分母样本数` | 同上，100% − 99% = 1% |
| 比例阈值（≥99.5%） | `预算 = 0.5% × 分母样本数` | 直接取补 |
| 绝对金额（≤0.01%） | `预算 = 0.01% × 月流水金额`，**少计 / 多计各记一份** | `REL-019` 要求分列，合并即失败 |
| 计数型（挂死轮次 / 白名单外注册 / 不可计费用量 / 迁移 `FAILED`） | `预算 = 0`；任一次即触发硬告警并消耗 | `REL-124` 硬告警清单 |

### 3.2 分账与不得互抵

| 规则 | 内容 | 拦截点 |
|---|---|---|
| 归因即账本 | `budgetOwner` 必须等于 `attribution`（§1.1） | 登记表 CI |
| 三方分账 | 平台 / 模型 / 依赖三本账独立累计；模型责任失败**不得**消耗平台预算（`REL-026`） | 错误预算记账器（按归因分账） |
| 不得挪用 | 不得跨 `sloId` 挪用或抵扣（`REL-123`） | 记账器分账审查 + 报表 schema |
| 不得事后改归因 | 归因在事件产生时定型；补录归因必须留变更审计 | 记账器写入前置校验 |
| 冻结阈值 | 消耗 ≥50% 触发预警；≥100% 触发冻结清单（清单与解冻条件见 `REL-DOC-12` §4） | 发布流水线预算门禁（`REL-122`） |
| 一致窗口 | 可用性 / 预算 / 降级级别必须同钟源、同窗口定义（1 h 与 30 天两套窗口显式登记） | 观测平台统一时间轴（`REL-127`） |

### 3.3 降级期样本

降级期（L1 / L1b / L2 / L3）样本**必须**计入 P95 / P99 与可用率统计，**不得**按级别过滤；报表必须另置「降级期分布」分组（`REL-126`）。
