## 1. 台账 schema（`REL-027` 六字段为必填）

| 字段 | 必填 | 说明 | 校验点 |
|---|---|---|---|
| `参数号` | 是 | `PP-xx`，只增不改号 | CI：格式 + 唯一 |
| `参数名` | 是 | 与代码 / 配置键一致 | CI：非空 |
| `落点` | 是 | Profile 字段 / 平台配置中心键 / 报表字段 / 派生结论 | CI：非空；Profile 字段须存在于 `contracts/profile.schema.json` |
| `用途` | 是 | 该参数被哪个判定式消费 | CI：非空 |
| `影响需求 ID` | 是 | `REL-###` 列表 | CI：ID 可解析 |
| `回填阶段` | 是 | `P1` / `P2` / `P3` / `P4` | CI：枚举；**最迟 P4** |
| `负责人` | 是 | 角色（非人名） | CI：枚举自 §5 角色表 |
| `回填方法` | 是 | 可执行的测量 / 构造方法 | CI：非空，须含方法类型 |
| `验收证据` | 是 | 留证形态 | CI：非空 |
| `当前状态` | 是 | `设计初值` / `无初值` / `冲突` | CI：枚举 |

| `引用点` | 是 | 该参数的**全部**引用位置（单一真源校验） | CI：`REL-063` / `REL-067` / `REL-093` 要求跨文件同源 |
