## 1. 级别枚举与状态 schema（`REL-037` / `REL-049`）

### 1.1 级别枚举（封闭，出现枚举外取值即失败）

| 级别 | 名称 | 语义 | 是否阻断执行 |
|---|---|---|---|
| `L0` | 正常 | 全功能 | 否 |
| `L1` | 软降级 | 软依赖不可用，缓冲继续 | **否** |
| `L1b` | 缓冲耗尽 | 有界丢弃 + `reconciled:false` 墓碑 | **否** |
| `L2` | 缓存降级 | 用 TTL 内清单继续；停止新建域 | 否（仅拒新建域） |
| `L3` | 硬停 | fail-closed 拒绝当前轮次 | **是** |

### 1.2 `domain.degraded` 事件 schema（`REL-049`，缺字段即失败）

| 字段 | 类型 | 必填 | 取值 / 说明 | 校验点 |
|---|---|---|---|---|
| `eventType` | string | 是 | 固定 `domain.degraded` | 事件 schema |
| `scope` | string | 是 | `domain:{domainId}` 或 `global` | `REL-037`：缺 `scope` 即失败 |
| `dimension` | enum | 是 | `DIM-01`…`DIM-07` | `REL-037`：缺 `dimension` 即失败 |
| `subKey` | string | 条件必填 | `dimension=审计` 时必填，取值 `kind ∈ {audit, billing}` | `REL-052`：两个缓冲各自独立判定 |
| `prevLevel` | enum | 是 | `L0`…`L3` | 跃迁表校验 |
| `level` | enum | 是 | `L0`…`L3` | 枚举校验 |
| `reasonCode` | enum | 是 | §3 的 `TRG-*` 取值 | 原因码白名单校验（`REL-044`）；`reason=LEVEL_RECOVERED` 为回落专用 |
| `effectiveAt` | 单调时间戳 | 是 | 级别生效时刻（本地单调钟） | 与 `REL-127` 对齐时间轴 |
| `observedWindow` | object `{from, to, probeCount, failCount}` | 是 | 判定窗口 | `REL-039`：滞回判定输入 |
| `sloIds` | string[] | 是 | 受影响 SLO（§9） | 预算记账器分账 |

持久化：事件必须落**域外**事件存储并在域重启后仍可查（未持久化即失败）。级别状态接口 `GET /v1/domains/{id}/degradation` 返回同一 schema 的当前值 + 最近 N 次跃迁。

### 1.3 依赖维度（`DIM-*`，与 `REL-047` 枚举一一对应）

| ID | 维度 | 归属依赖 | 可产生的最高级别 |
|---|---|---|---|
| `DIM-01` | 模型路径 | 反向网关 / 凭证代理 / 模型网关 | L3 |
| `DIM-02` | 审批 | 域外审批服务 | L3 |
| `DIM-03` | 审计 | 一般审计落库（软）+ 最小审计集（硬，属 fail-closed 分支） | L3（最小集）/ L1b（一般审计） |
| `DIM-04` | 目录 | 目录服务（工具清单 / 模型目录 / 场景定义 / connector 清单） | L2 |
| `DIM-05` | 沙箱 | 沙箱后端 | L3 |
| `DIM-06` | 域池 | 域池与共享资源配额 | L3 |
| `DIM-07` | 持久层 | 会话日志持久层 / 写所有权 | L3 |

> **映射说明（不改变 `REL-047` 枚举）**：计费与一般审计同属 `DIM-03`，以 `subKey.kind` 分列为 `billing` / `audit` 两条独立判定链；`REL-052` 要求的独立水位、独立阈值、独立丢弃计数在该子键层实现，`REL-047` 要求的**按维度聚合**在 `dimension` 层实现。

## 2. 依赖维度 × 级别矩阵（触发 → 行为 → 对外）

| 触发（`TRG-*`） | 级别 | 行为（可执行动作） | 对外表现 | 依据 |
|---|---|---|---|---|
| 计费依赖探测连续 3 次失败或持续 ≥30 s | `L1` | 计费缓冲继续；**不阻断执行** | 用量延迟展现 | `REL-038` |

## 3. 进入 / 退出阈值与最短驻留（`REL-038`–`REL-044`）

### 3.1 通用滞回参数

| 参数 | 取值 | 来源 |
|---|---|---|
| 进入判定 | 连续 3 次探测失败**或**持续失败 ≥30 s（先到者） | `REL-038`、`REL-042` |
| 退出判定 | 依赖恢复且连续 **5 min** 稳定 | `REL-039` |
| 最短驻留 | **5 min**（驻留期内单次探测成功**不得**触发退出） | `REL-039` |
| 探测间隔 | ≤10 s（由「3 次失败 / 30 s」反推：3 × 10 s = 30 s，两条件同量级） | 本文件推导 |
| 滞回防抖 | 退出阈值必须严于进入阈值；L1b 退出阈值 = 进入阈值的 50% | `REL-041` |

### 3.2 逐级阈值表

| 触发 ID | 级别 | 进入条件（判定式） | 退出条件（判定式） | 最短驻留 | 退出附加动作 | 依据 |
|---|---|---|---|---|---|---|
| `TRG-L1-BILL` | `L1`（`DIM-03/billing`） | `failStreak ≥ 3 ∨ failDuration ≥ 30 s` | `successStreak ≥ 5 min` | 5 min | 排空补传（带抖动，见 `REL-DOC-05` §3） | `REL-038`、`REL-039` |
| `TRG-L1-AUDIT` | `L1`（`DIM-03/audit`） | 同上 | 同上 | 5 min | 同上 | `REL-038`、`REL-039` |
| `TRG-L1b-AUDIT` | `L1b`（`kind=audit`） | `oldestEventAge ≥ retainHours` **或** 字节 ≥ `PP-28`（先到者） | `oldestEventAge ≤ 50% × retainHours` 且稳定 5 min | 5 min | 退出后 5 min 内不得再次进入（观测窗口约束） | `REL-040`、`REL-041` |
| `TRG-L1b-BILL` | `L1b`（`kind=billing`） | 同上（独立水位、独立计数） | 同上（独立判定） | 5 min | 同上 | `REL-040`、`REL-052` |

| `TRG-L3-(b)` | `L3`（`DIM-02`） | 审批不可用或超时（`SEC-063`；超时判定见 `REL-DOC-10` §2） | 同上 | 0 | 同上 | `REL-044`(b) |
| `TRG-L3-(c)` | `L3`（`DIM-03/最小集`） | 最小审计集不可用（`SEC-070`） | 同上 | 0 | 同上 | `REL-044`(c) |
| `TRG-L3-(d)` | `L3`（`DIM-05`/就绪判据） | 域就绪判据失败（`SEC-044`） | 重走就绪判定全绿 | 0 | 同上 | `REL-044`(d) |
| `TRG-L3-(e)` | `L3`（`DIM-05`） | 沙箱后端不可用（`SANDBOX_UNAVAILABLE`） | 同上 | 0 | 同上 | `REL-044`(e) |
| `TRG-L3-(f)` | `L3`（`DIM-06`） | 域池耗尽（503 并排队 + 全局背压） | 池水位恢复 + 稳定 5 min | 0 | 同上 | `REL-044`(f) |

### 3.3 L3 触发集穷尽性校验（`REL-044` / `REL-045`）

1. 原因码白名单 = §3.2 中 `TRG-L3-(a)`–`(h)` 共 8 项；出现白名单之外的 L3 原因码即失败。
2. 逐项注入 (a)–(h) 各 5 min，断言：任意时刻级别 = `L3`，且不存在「已是 L3 但仍受理新 turn」的组合。
3. 硬依赖（(a)–(h)）不得停留或回落于 `L0` / `L1` / `L1b` / `L2`（`REL-045`）。

## 4. 跃迁规则（`REL-048`）

| 规则 | 内容 | 拦截点 |
|---|---|---|
| 升级 | 更严重方向**立即生效**，**允许跳级**（例：同时触发目录不可用 + 最小审计集不可用 ⇒ 立即 `L3`） | 级别状态机跃迁表校验 |
| 降级 | **必须**逐级满足退出条件，**不得**跨级回落；`L3 → L2 → L1 → L0` 逐级 | 级别状态机跃迁表校验 |
| L2 → L0 | 禁止直连；必须经 `强制刷新目录 + 重新 attest`（`REL-043`） | 重 attest 强制调用点 |
| L1b → L0 | 必须经 `L1`（不得 `L1b → L0` 直跳） | 跃迁表 |
| 禁止路径 | `L3 → L0`、`L3 → L1`、`L2 → L0`（未重 attest）、`HANDOFF` 类禁区见 `REL-DOC-07` | 跃迁表静态校验 |

### 4.1 跃迁矩阵（行 = 当前，列 = 目标；`✓` 允许，`✓*` 允许但附条件，`✗` 禁止）

| 当前 \ 目标 | `L0` | `L1` | `L1b` | `L2` | `L3` |
|---|---|---|---|---|---|
| `L0` | — | ✓ | ✓ | ✓ | ✓ |
| `L1` | ✓*（5 min 稳定） | — | ✓ | ✓ | ✓ |
| `L1b` | ✗ | ✓*（50% 滞回 + 5 min） | — | ✓ | ✓ |
| `L2` | ✓*（重 attest 通过且指纹未变） | ✓* | ✓* | — | ✓ |
| `L3` | ✗ | ✗ | ✗ | ✓*（逐级，且依赖恢复 + 5 min） | — |

## 5. 跨作用域聚合（`REL-047`）

| 规则 | 内容 | 校验 |
|---|---|---|
| 按维度分别聚合 | 全局级别按 `dimension` 分别聚合；同一维度内取**最严重者** | 聚合器输出 schema |
| 不得跨维度合并 | 不同维度**不得**互相比严重度后合并为单值 | 构造「域 A 因目录 L2、域 B 因审计 L1b」，输出必须分列；合并成单一 `L2` 即失败 |
| 子键分列 | `DIM-03` 内 `audit` / `billing` 两个 `subKey` 必须分列且独立判定 | 「审计缓冲打满」用例：计费维度水位与丢弃计数必须不变 |
| 作用域显式 | 每条级别状态必须携带 `scope`（`domain:{id}` 或 `global`） | `REL-037` |
| 视图 | 全局视图字段：`{dimension, subKey, worstLevel, affectedScopes[], effectiveAt}` | §1.2 |

## 6. 每级成本表（`REL-051`：损失项必须量化到可计量单位）

| 级别 | 可用性收益（可计量） | 一致性 / 计量损失（可计量） | 量化式 | 数据来源 |
|---|---|---|---|---|
| `L0` | 全功能；可用性目标 99.9% | 0 | — | `SLO-01` |
| `L1` | 软依赖故障期间新 turn 受理率维持 100%（避免的拒绝数 = 该窗口 turn 数） | 计量与审计**延迟展现**，非丢失 | `延迟事件数 = oldestEventAge × PP-31{kind}`；延迟金额 = 延迟事件折算用量（T+24 h 内可对账 ⇒ 不计入 `SLO-22`） | `buffer.oldest_event_age.seconds` |
| `L1b` | 软依赖故障期间仍 100% 受理（避免的拒绝数 = 该窗口 turn 数） | **不可计量用量（金额）** 与**丢弃事件数** | `丢弃事件数 = buffer.discard.tombstone.count`；`金额 = Σ 丢弃量估算`，受 `PP-15` 封顶；**每笔丢弃一条墓碑**（计数必须相等） | 墓碑表 + `usage.unmetered.cumulative` |
| `L2` | 目录故障期间既有域继续服务（受影响会话 = 0） | 新建域被拒（拒绝数 = 该窗口新建域请求数）；指纹漂移时排空域（排空会话数 × 单会话迁移成本） | 拒绝数 = 域创建准入计数；排空会话数 = `drain-domain` 事件计数 | 域创建准入 + 审计 |
| `L3` | fail-closed 保证安全与计量边界（避免的违规动作数 = 被拒动作数） | 拒绝的 turn 数 × 时长；可用性预算消耗 | `预算消耗 = 中断时长 / 43200 min × 100%`（对照 `SLO-01` 的 43.2 min/月）；通知数 = 受影响租户数 | `SLO-01` 预算记账器 + 通知记录 |

> 成本表**必须**在级别定义变更时同步更新（`REL-051`）；「损失」列为定性描述的级别**不得**启用。

## 7. 告警与通报（`REL-050`、`REL-121`）

| 条件 | 动作 | 载荷必填（`REL-125`） | 客户可见文案标识 |
|---|---|---|---|
| `L2` 持续 > 5 min | 告警 + 通知租户 | `{scope, dimension, effectiveAt, textId}` | `PRD-052`（状态页与维护窗口） |
| 任意 `L3` 触发 | 告警 + 通知租户 | 同上 + `reasonCode` | `PRD-037`（L1b）/ `PRD-039`（限速）/ 会话暂停提示 |
| `L1b` 触发 | **硬告警**（不得降级为通知，`REL-124`） | 同上 + `kind` + 丢弃计数 | `PRD-037` |
| 进入任一非 `L0` 级别 | 按 `(租户, 维度, 子键, 级别)` 聚合为一条；仅在跨过驻留阈值后告警 | 同上 | — |
| 单次探测失败 | **不告警** | — | — |

聚合校验：注入 1000 个域同时经历 10 s 依赖抖动 ⇒ 告警条数 ≤ 1 条/租户/维度（逐探测告警即失败）。

## 8. 软依赖与硬依赖的边界校验

### 8.1 软依赖禁止清单（`REL-046` / `REL-059`）

| 软依赖 | 不得导致的后果 | 静态校验 | 演练判据 |
|---|---|---|---|
| 计费 | 新 turn 被拒 / 轮次被中止 / 并发被降 | 轮次拒绝原因码白名单不含软依赖取值 | 停机 6 h ⇒ L3 计数 = 0、受理率 100% |
| 一般审计 | 同上 | 同上 | 同上 |
| 配额账本 | 同上 | 同上 | 同上 |
| 会话索引 | 同上 | 同上 | 同上 |
| 用量派生视图 | 同上 | 同上 | 同上 |
| 缓冲状态（水位 / 丢弃） | 同上 | 拒绝原因码静态校验 + 代码审查 | 缓冲打满 6 h ⇒ 受理率 100% |

### 8.2 硬依赖不得可降级（`REL-045`）

§3.3 的 (a)–(h) 任一不可用时，级别**不得**停留或回落于 `L0` / `L1` / `L1b` / `L2`；拦截点为「级别判定器 + 轮次准入联合校验」。
