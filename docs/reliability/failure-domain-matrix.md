## 1. 矩阵 schema

### 1.1 字段定义

| 字段 | 类型 | 必填 | 说明 | 校验点 |
|---|---|---|---|---|
| `faultId` | string `^FDM-\d{2}$` | 是 | 矩阵行号 | 唯一 |
| `fault` | string | 是 | 故障描述 | 非空 |
| `blastScope` | string | 是 | 影响范围（会话数 / 域数 / 租户数口径） | 非空 |
| `rto` | string | 是 | RTO 目标或档位引用 | **禁止空值**（`REL-065`） |
| `rpo` | string | 是 | RPO 目标或档位引用 | **禁止空值**；单节点行 **不得写 0** |
| `rtoClass` | enum `秒级` / `分钟级` / `恢复型(分钟到小时级)` | 是 | 档位；**互斥规则见 §1.2** | 档位校验 |
| `drillId` | string `^DRL(-[A-Z]\d{2})?$` | 是 | 绑定的可执行演练用例（`REL-DOC-11`） | 无映射行**不得**进入对外承诺（`REL-060`） |
| `paramRefs` | string[] `^PP-\d{2}$` | 是 | 该行数值来源参数 | 须存在于 `REL-DOC-02` |
| `capacityVersion` | string | 是 | 绑定的容量参数版本（§5） | 与 `REL-067` 绑定校验 |
| `declaredExternally` | boolean | 是 | 是否进入对客声明（`PRD-053`） | `drillId` 为空时不得为 `true` |

### 1.2 档位互斥规则（`REL-065`）

| 规则 | 内容 | 校验 |
|---|---|---|
| 单节点 ≠ 单 AZ | 单 AZ 行必须为 `恢复型(分钟到小时级)`，**不得**与单节点行同 `rtoClass` | 矩阵模板校验 |
| 单节点 RPO | **必须** = 复制滞后（`PP-06`），**不得**写 0 | 模板校验（正则拒绝 `0`） |
| 单会话 / 单域 RPO | 节点内 RPO = 0，但必须同时暴露「未 flush 追加量」与「未上传尾部量」 | 报表 schema（`REL-DOC-09` §4） |
| 禁空值 | 任一行的 `rto` / `rpo` 为空即失败 | 模板校验（`EVO-028`） |
| 跨 AZ 表述 | 对外必须表述为「恢复」而非「重调度」，且不得表述为秒级切换 | `PRD-053` 会签 |

### 2.1 connector 上游故障的附加要求（`FDM-07`）

| 项 | 要求 | 校验 |
|---|---|---|
| 不得摘域 | 重连耗尽后由 Connector 控制器自动重载，**摘域计数 = 0** | `DRL-03` 判据 (a) |

## 3. 反亲和与密度上限（`REL-062` / `REL-063`）

### 3.1 强制调度约束

| 约束 | 判定式 | 拦截点 | 性质 |
|---|---|---|---|
| 单节点租户数上限 | `tenantsOnNode ≤ min(PP-21, ⌊PP-22 × 租户总数⌋)` | 调度器反亲和约束（preventive，准入拒绝） | 硬 |
| 取严原则 | 两个上限取**更严格者**生效，两处取值必须同源（§5） | 参数单一真源校验 | 硬 |
| 不得替代 | **不得**以「同一租户多隔离组分散到不同节点」替代本约束 | 调度策略代码审查 + 用例 | 硬 |
| 一租户一域默认 | 默认一租户一域；多隔离组额外占用域槽位 | 域池计数 | — |

### 3.2 校验用例

| 用例 | 注入 | 通过判据 |
|---|---|---|
| 1000 租户调度 | 提交 1000 个租户的调度请求 | 任一节点租户数 ≤ 上限；违规分配数 = 0 |
| 资源放大不变性 | 人为放大单节点资源后重跑 | 上限**不变**（证明反亲和是独立约束，非资源推导的副产品） |
| `Y%` 敏感性 | 将 `PP-22` 在其 ±20% 区间内变动 | 单节点租户数上限随 `PP-22` 线性变化，且两处引用同源 |

## 4. `N_node` 推导表（`REL-061`）

### 4.1 判定式

```
N_mem  = ⌊ PP-16 / PP-17 ⌋
         PP-17 = PP-18 + PP-33（域内存预留 = 单域峰值内存 + 缓冲折算配额）

N_blast = min( PP-19 , ⌊ PP-20 × T_sla ⌋ )
         T_sla = SLA 恢复时长承诺（合同输入）
         推导：若全部 N 个租户受影响，须在 T_sla 内恢复完毕 ⇒ R_rec × T_sla ≥ N
              故 N 的上界为 ⌊R_rec × T_sla⌋，再受「允许受影响租户数上限」封顶

N_node = min(N_mem, N_blast)
```

### 4.2 输入、来源与敏感性（`±20%`）

| 输入 | 参数 | 来源类型 | 当前状态 | −20% | +20% | 对 `N_node` 的影响方向 |
|---|---|---|---|---|---|---|
| 节点可用内存 | `PP-16` | 实测（目标机型） | 待回填 | `N_mem` ↓20% | `N_mem` ↑20% | 正相关；敏感性 ±20%（线性） |
| 域内存预留 | `PP-17` | 实测派生（`PP-18` + `PP-33`） | 待回填 | `N_mem` ↑25% | `N_mem` ↓16.7% | 负相关；**倒数敏感**（比 `PP-16` 更敏感，容量评审必须优先收紧该项） |
| 单域峰值内存 | `PP-18` | 实测（单域压测） | 待回填（设计 §14 #11 未实测项） | — | — | 经 `PP-17` 传递 |
| 允许受影响租户数上限 | `PP-19` | 合同 / SLA 反推 | 待回填 | `N_blast` ↓20% | ↑20% | 正相关 |
| 单位时间可恢复域数 | `PP-20` | 实测（批量恢复压测） | 待回填 | `N_blast` ↓20% | ↑20% | 正相关 |
| SLA 恢复时长承诺 | 合同输入 | 合同 | 已定（`PRD-050`/`PRD-052` 定稿） | `N_blast` ↓20% | ↑20% | 正相关 |

### 4.3 数值示例（**示例值，非承诺值**；实际以 `PP-16`–`PP-22` 实测回填）

| 步 | 输入 | 示例取值 | 推导 |
|---|---|---|---|
| 1 | `PP-16` 节点可用内存 | 256 GiB | — |
| 2 | `PP-18` 单域峰值内存 | 2 GiB | — |
| 3 | `PP-33` 缓冲折算配额 | 0.5 GiB | 由 `PP-31` × `retainHours` 折算 |
| 4 | `PP-17` 域内存预留 | 2.5 GiB | 2 + 0.5 |
| 5 | `N_mem` | 102 | `⌊256 / 2.5⌋` |
| 6 | `PP-20` 单位时间可恢复域数 | 2 域/min | 实测 |
| 7 | `T_sla` | 30 min | 合同 |
| 8 | `PP-19` 允许受影响租户数 | 50 | 合同反推 |
| 9 | `N_blast` | 50 | `min(50, ⌊2 × 30⌋) = min(50, 60) = 50` |
| 10 | `N_node` | **50** | `min(102, 50)` |

> 上表**必须**与容量模型（`REL-099`、`PP-25`、`PP-31`、`PP-33`）同源引用同一参数 ID；只有结论无输入、或无来源标注即失败（`REL-061`）。`N_node` 不得只由内存推出。

## 5. 版本绑定与单一真源（`REL-067` / `REL-063`）

| 项 | 规则 | 拦截点 |
|---|---|---|
| 版本绑定 | 矩阵头部必须携带 `capacityVersion`；任一 `PP-21` / `PP-22` / `PP-17` / `PP-19` / `PP-20` / `PP-25` / `PP-31` / `PP-33` 变更后，矩阵版本必须 +1 | 发布流水线版本绑定校验：参数版本 ≠ 矩阵版本即失败 |

## 6. workspace 独占租约与 fencing（`REL-068`）

| 项 | 要求 | 拦截点 |
|---|---|---|
| 独占 | 同一 workspace 卷在任一时刻只被**一个域可写** | 租约服务（写租约申请前置校验） |
| 可转移 | 租约携带 `epoch`；迁移时 `epoch + 1`，旧持有者 append 被拒 | fencing 校验 + `REL-DOC-07` §2 |
| 拒绝行为 | 第二个域的写租约请求**被拒绝**并产生审计事件 | 审计事件 `workspace.lease.denied`（键含 `(tenantId, isolationGroupId, workspaceId)`） |
| 不得替代 | `session.lock` 只护单会话，**不护** workspace；不得以会话锁替代租约 | 代码审查 + 双写者用例 |
| 容量溢出路径 | 走「同域扩容 / 排空 + 迁移会话」，**不得**「新建隔离组共享 workspace」 | 容量变更评审 |
| 门禁 | `GATE-004` 条件 4（workspace 独占租约生效） | `GATE-004` 出口检查 + `DRL-E11` |

## 7. 域级资源限制与自伤防护（`REL-064`）

| 项 | 要求 | 判据 |
|---|---|---|
| 隔离 | 单域超限时**仅该域**被终止，同节点其他域存活 | 注入单域内存至其 `limit` 的 200%：同节点其他域的可用性事件计数 = 0；出现跨域连带终止即失败 |
