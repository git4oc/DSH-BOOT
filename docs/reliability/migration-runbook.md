## 1. 状态机与跃迁表（`REL-077` / `REL-078`）

### 1.1 状态

| 状态 | 含义 | 允许的下一状态 |
|---|---|---|
| `PENDING` | 迁移已受理，源域仍可写 | `HANDOFF_ARMED`、`FAILED` |
| `HANDOFF_ARMED` | 源域已静默且轮次已收敛，目标域预备中 | `SOURCE_RELEASED`、`FAILED` |
| `SOURCE_RELEASED` | 源域已 flush / 关闭句柄 / 释放 `session.lock` | `OWNED`、`FAILED` |
| `OWNED` | 目标域提交 epoch 并成为唯一写者 | `ROUTED`、`FAILED` |
| `ROUTED` | 路由已切换到目标域（终态） | — （终态） |
| `FAILED` | 任一步失败（可幂等重驱动） | `PENDING`（重驱动入口）、`FAILED`（再次失败） |

### 1.2 跃迁矩阵（行 = 当前，列 = 目标）

| 当前 \ 目标 | `PENDING` | `HANDOFF_ARMED` | `SOURCE_RELEASED` | `OWNED` | `ROUTED` | `FAILED` |
|---|---|---|---|---|---|---|
| `PENDING` | — | ✓ | ✗ | ✗ | ✗ | ✓ |
| `HANDOFF_ARMED` | **✗（禁止静默回退）** | — | ✓ | ✗ | ✗ | ✓ |
| `SOURCE_RELEASED` | ✗ | ✗ | — | ✓ | ✗ | ✓ |
| `OWNED` | ✗ | ✗ | ✗ | — | ✓ | ✓ |
| `ROUTED` | ✗ | ✗ | ✗ | ✗ | — | ✗（终态，不得再变） |
| `FAILED` | ✓（唯一重驱动入口） | ✗ | ✗ | ✗ | ✗ | — |

| 规则 | 内容 | 校验 |
|---|---|---|
| 回退边界 | `HANDOFF_ARMED` **之前**允许回退；之后**必须**走 `FAILED` + 重驱动，**不得**静默回退 | 跃迁表静态校验（禁止 `HANDOFF_ARMED → PENDING`） |
| 无写者禁止 | **不得**停留在 `SOURCE_RELEASED` 而无重驱动；失败必须进入 `FAILED` | 状态看护 + 用例 |
| 失败终态可达 | 三个中间态任一失败都必须能进入 `FAILED` | 注入用例 `DRL-02` |
| 终态唯一 | 每次迁移有且仅有一个终态（`ROUTED` 或 `FAILED` 转出的再次迁移） | 事件流校验 |

## 2. 断言清单（步骤 → 断言 → 拦截点）

| 步骤 ID | 步骤 | 断言（判定式） | 性质 | 失败处置 | 证据 |
|---|---|---|---|---|---|
| `MIG-01` | 源域静默：拒绝新 turn | 静默开关生效后新 turn 受理率 = 0 | preventive | 迁移不启动；告警 | 静默开关状态事件 |
| `MIG-02` | 等待 / 取消当前轮次 | 若存在开放轮次，取消必须在 ≤ 剩余 `T_turn` 内完成（`REL-DOC-10` §4） | preventive | 超时 ⇒ 按 `CHK-05` 升级处置 | 取消事件 + 计时 |
| `MIG-03` | 目标域预备：`open` 就绪、connector 预连、取得可转移租约（`epoch + 1`） | 目标就绪判定全部为真 | preventive | 进入 `FAILED` | 目标就绪报告 |
| `MIG-04` | **`assert targetBaseSeq == sourceLastReplicatedSeq`** | 严格相等；不等即**拒绝 handoff** | **preventive（核心）** | 进入 `FAILED`；指标记录 `targetBaseSeq < sourceLastReplicatedSeq` | 审计事件 + 指标 |
| `MIG-05` | 源域：追加 closer / `flush` → 关闭句柄 → 释放 `session.lock` | ① closer 追加幂等（按 `(turnId, callId)` 去重）② `flush` 成功 ③ 句柄关闭 ④ 锁释放可验证 | preventive | 进入 `FAILED`；不得跳过 | 审计事件 + 锁状态 |
| `MIG-06` | 目标域提交 epoch；源在 epoch 提升后的 `append` **被拒** | 源域后续 `append` 返回拒绝错误；审计记录产生 | preventive（fencing） | 出现双写者即失败 | fencing 拒绝审计 |
| `MIG-07` | 切换路由 | 路由表指向目标域且源域不再接收 turn | preventive | 进入 `FAILED` | 路由变更事件 |

> 每个断言的失败都必须携带 `{migrationId, step, reasonCode, observed, expected}` 并向 `FAILED` 转移（`REL-077`）。

## 3. 静默、等待上界与准入（`REL-081` / `REL-088`）

### 3.1 源域静默与有界等待

| 项 | 规则 |
|---|---|
| 静默 | 源域在 `MIG-01` 后拒绝新 turn（不排队、不降级到共享域） |
| 等待上界 | 「等待或取消当前轮次」必须有界：**≤ 剩余 `T_turn`**；`T_turn` 到期时轮次被取消并继续迁移 |
| 禁止 | 无限等待（无上界的等待路径即失败） |
| 观测 | 源域静默时长、轮次取消耗时、迁移状态停留时长 |

### 3.2 轮次边界准入（`REL-088`）

| 项 | 规则 | 拦截点 |
|---|---|---|
| 准入 | 迁移**只能**在轮次边界发起；轮次内（`turn.started` 与终态之间）发起必须被拒绝并携带原因 | 迁移准入检查（preventive） |
| 原因码 | 拒绝原因码封闭：`TURN_IN_PROGRESS`、`SOURCE_NOT_HANDOFF_ABLE`、`PRECONDITION_FAILED` | 原因码白名单 |
| 用例 | 在 `started` 与终态之间发起迁移 ⇒ 被拒 + 原因码 | `DRL-02` 前置分支 |

## 4. 锁卡死处置流程（`REL-082`）

### 4.1 事实约束

| 事实 | 后果 |
|---|---|
| `session.lock` **故意无过期** | 不存在「等待自动过期」的路径；出现该代码路径即失败 |
| 取得写所有权唯一方式 = `open(id,'write')` | 遇既有持有者必须拒绝（`SessionAlreadyOwnedError`），**不得**排队、**不得**依赖超时兜底（`CTR-001` §5.3 P-3） |
| `SessionOwnershipLostError` 无参考行为基线 | 租约续期 / 过期阈值必须由本方案自定义；该阈值当前**无 `ENG-*` ID 归属**（`CTR-001` §8 #3）⇒ 列为未闭合项（§9 #1） |

### 4.2 检测指标与阈值

| 指标 | 口径 | 告警阈值 | 推导 |
|---|---|---|---|
| `lock.writeOwnershipWait.seconds` | 自「需要写所有权」到「取得或放弃」的时长 | 5 min ⇒ 告警；2× = 10 min ⇒ 升级 | 5 min 与 `SLO-11`（无写者会话时长 P99 ≤ 5 min，`REL-016`/`REL-084`）同源，避免两套阈值 |
| `lock.holder.alive` | 持有者进程 / 域活性探测结果 | 探测失败 ⇒ 进入 `SOP-03` 分支 | — |
| `migration.stuck.count{state}` | 状态停留超阈的迁移数 | ≥1 且超 5 min | `REL-084` |

### 4.3 处置 SOP

| 步 | 动作 | 判定 / 命令入口 | 禁止 |
|---|---|---|---|
| `SOP-01` | 定位持有者：从锁记录取出 `{domainId, processId, epoch, acquiredAt}` 并关联 `migrationId` | 锁记录查询接口 | 不得凭猜测摘域 |
| `SOP-02` | 活性判定：探测持有者进程 / 域是否仍在运行（心跳 + 进程存在性） | `lock.holder.alive` | 不得以「锁文件存在」直接判定持有者存活 |
| `SOP-03` | **存活分支**：对该域执行轮次取消（`REL-DOC-10` §4）→ `drain-domain` → 触发正常释放（closer + `flush` + `close`） | 取消与排空入口 | 不得跳过 closer 直接释放 |
| `SOP-04` | **死亡分支**：域外确认无活动写者（校验 `flock` 实际可用且无持有者）→ 摘域 → 允许目标域在 `epoch + 1` 下重新取得所有权 | 摘域审批 + 所有权重建入口 | **不得**在未验证 `flock` 无持有者的情况下释放，否则产生双写者 |
| `SOP-05` | 迁移侧：将卡住的迁移置 `FAILED`，走 §5 重驱动 | 重驱动入口 | 不得手工改状态绕过状态机 |
| `SOP-06` | 留证：全过程写审计（含操作者、时刻、判定依据、前后锁状态、epoch） | 审计键 `(tenantId, isolationGroupId, workspaceId, sessionId)` | 无留证即视为未处置 |
| `SOP-07` | 复盘：若 `SOP-04` 触发，必须在 24 h 内核对是否存在重复事件或丢失事件（事件数不减少 + 幂等键去重计数） | 后置校验 `MIG-08` | 未核对不得关闭事件 |

### 4.4 用例

构造「持有写锁但不退出的进程」：必须在 5 min 内产生「写所有权等待时长超阈」告警并给出 `SOP-03`/`SOP-04` 处置入口；出现「等待自动过期」的代码路径即失败。

## 5. 重驱动 SOP（`REL-080`）

### 5.1 幂等键与步骤

| 项 | 规则 |
|---|---|
| 幂等键 | `(migrationId, step)` —— 同键重驱动必须无副作用 |
| 入口 | 仅 `FAILED → PENDING` 一条入口；重驱动必须复用原 `migrationId` |
| 步骤重放 | 重驱动从**失败步的前一步**重放（前一步的断言必须重跑），不得跳步 |
| 允许重复 | `MIG-05` 的 closer 追加（按 `(turnId, callId)` 去重）、`MIG-06` 的 epoch 提交（同 `epoch` 重复提交为幂等 no-op）、`MIG-07` 的路由切换（幂等） |
| 禁止 | 产生重复 closer、重复 epoch 提升、重复路由切换 |
| 次数上限 | 同一迁移连续重驱动 ≥3 次仍失败 ⇒ 转入人工处置（`SOP-01`–`SOP-07`），并硬告警 |

### 5.2 幂等断言（逐点注入失败后重驱动）

| 注入点 | 断言 | 判据 |
|---|---|---|
| `HANDOFF_ARMED` | 最终状态一致；事件数不减少；单一写者 | 事件数单调不减 + 无双写者 |
| `SOURCE_RELEASED` | 不产生重复 closer / epoch / 路由切换 | 去重后计数与单次迁移一致 |
| epoch 提交 | 同上 | 同上 |
| 全部三点 | 每次进入 `FAILED` 且可重驱动至 `OWNED`；无样本最终停留中间态 | 用例 `DRL-02` |

## 6. 前置校验清单（preventive）

### 6.1 写路径介质（`REL-085`）

| 项 | 规则 | 拦截点 |
|---|---|---|
| 介质 | 会话日志写路径**不得**位于共享 NFS / FUSE（NFSv3 不可靠） | 部署清单静态校验（preventive）+ 启动自检 |
| 拓扑 | 每域**本地卷 + 异步复制** | 部署清单 |
| 失败后果 | 出现网络文件系统挂载即门禁失败 | CI / 清单校验 |

### 6.2 format 版本（`REL-086`）

| 项 | 规则 |
|---|---|
| 前置 | 目标域 `format` 版本 **必须** == 会话日志 `format` 版本 |
| 不等处置 | 迁移被拒，且**不可重驱动到该目标**（终态绑定目标域） |
| 附加断言 | 目标卷**零写入**（拒绝发生在任何写之前） |
| 拒绝方向 | 不能解码的格式必须被拒绝，不得尝试升级或宽松解码（`CTR-001` §5.3 P-7、`EVO-010`） |
| 用例 | `DRL-E21` |

### 6.3 preset 可达性（`REL-087`）

| 项 | 规则 |
|---|---|
| 前置 | 目标域必须能解析该会话引用过的**全部** preset id |
| 不等处置 | 迁移被拒（**非**恢复后失败） |
| 平台级不变量 | 任何域都必须能解析全平台历史会话引用过的全部 preset id；否则该域不得作为迁移目标 |
| 用例 | `DRL-E21` 变体（缺失 preset id） |

### 6.4 其他前置

| 项 | 规则 | 依据 |
|---|---|---|
| 会话状态 | 仅 `active` / `idle` 可迁移 | 设计 §4.3 |
| workspace 租约 | 目标域必须能取得 workspace 写租约（`epoch + 1`） | `REL-068`、`REL-DOC-06` §6 |
| 轮次边界 | 见 §3.2 | `REL-088` |
| 禁止的接管 | **不得**依赖「重载后端插件即静默接管日志」 | 设计 §5.4.1 |

## 7. 后置校验与不变量

### 7.1 `MIG-08` 事件数不减少（`REL-089`）

| 项 | 规则 |
|---|---|
| 断言 | 比较源域最后已复制 `seq` 与目标域可读事件数：`targetReadableCount ≥ sourceLastReplicatedSeq` |
| 失败 | 迁移置 `FAILED` + 告警；**不得**静默继续 |
| 一致性断言组 | `REL-015` 的迁移成功率分子要求「迁移完成**且**断言通过」，本断言为其中一项 |
| 用例 | 令目标域读到更旧副本 ⇒ 后置校验失败、`FAILED`、告警（`DRL-E21` 变体） |

### 7.2 epoch 提交后 fencing（`REL-083`）

| 项 | 规则 |
|---|---|
| fencing | `epoch` 提升后源域 `append` **必须被拒绝** |
| 审计 | 被拒事件必须进审计（键含 `(tenantId, isolationGroupId, workspaceId, sessionId)`） |
| 失败 | 出现双写者即失败 |
| 用例 | 迁移完成后令源域继续 `append` |

## 8. 无写者时长看护与告警（`REL-084`）

| 项 | 规则 |
|---|---|
| 指标 | `migration.nowriter.seconds`（`HANDOFF_ARMED` → 目标域 `OWNED`） |
| SLO | `SLO-11`：P99 ≤ 5 min（`REL-016`）；样本**必须**包含进入 `FAILED` 后重驱动的会话 |
| 告警条件 | 无写者时长 > 5 min（任一迁移，不等 P99） |
| 告警载荷 | **必须**含 `migrationId` 与当前状态（`{migrationId, state, nowriterSeconds, sourceDomain, targetDomain}`） |
| 用例 | 把某迁移卡在 `SOURCE_RELEASED`：5 min 内告警且载荷含上述字段（`DRL-02`） |
