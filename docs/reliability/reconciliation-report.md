## 1. 真源模型（`REL-090`）

| 角色 | 内容 | 性质 |
|---|---|---|
| **唯一真源** | 会话事件日志 + **上传确认水位** | 追加型；水位界定「哪些已离开节点」 |
| 派生视图 | 配额账本、计费、审计补写、会话索引、用量派生视图 | **可重建、允许落后**；**不得**作为裁定依据 |

| 禁止项 | 校验 |
|---|---|
| 「以账本为准」的裁定路径 | 数据字典与裁定代码路径审查；出现即失败 |
| 「以索引为准」的裁定路径 | 同上 |
| 用派生视图覆盖日志前缀 | 裁定回写必须只写派生视图，**不得**改写日志 |

## 2. 上传与水位

### 2.1 上传确认水位（`REL-091`）

| 项 | 规则 |
|---|---|
| 驱动来源 | 必须由**域外对象存储的接收确认**驱动；**不得**由域内自报（安全事件权威来源在域外，`SEC-071`） |
| 单调性 | 水位**必须**单调不减；回退即失败 |
| 更新点 | 域外确认回调；域内上报只作交叉核验 |
| 注入判据 | 域内上报水位前进但对象存储未确认 ⇒ 水位**不前进** |
| 与 RPO | 水位与本地尾部 `seq` 之差换算时间 = 跨节点 RPO（`SLO-09`，`PP-06`） |

### 2.2 帧完整性（`REL-092`）

| 项 | 规则 |
|---|---|
| 上传边界 | 必须对齐到**完整帧**（不得上传半帧） |
| 撕裂尾部 | 撕裂尾部截断只作用于**本地读**（`read()` 只返回合法连续前缀） |
| 重传起点 | 崩溃后重传必须从完整帧起始 |
| 注入判据 | 在 `flush` 中途 SIGKILL ⇒ 已上传对象中不存在半帧 |
| 水位语义 | 水位只能落在完整帧边界上；落在帧内即失败 |

### 2.3 `uploadInterval`（`REL-093`）

| 项 | 规则 |
|---|---|
| 单一真源 | 该参数必须同时进入 SLO（`SLO-09`）、容量模型（§5.2）与对账窗口定义；三处引用同一参数 ID `PP-25` |
| 冲突登记 | 设计文档 §7.6 给初值 30 s；§10.3 以 `F = 5 s` 推导 200 req/s ⇒ **同一参数两处不一致**，须由总纲维护者裁定（`REL-DOC-02` §4.1 #1） |
| 观测 | 必须暴露每域实际上传间隔分布 `upload.interval{domain}`（`SLO-23`） |
| 注入判据 | 人为拉长某域上传间隔 ⇒ 跨节点 RPO 同步上升、上传间隔分布同步变化 |

## 3. 对账作业 SOP

### 3.1 窗口与调度

| 项 | 规则 |
|---|---|
| 窗口 | `T+24 h` 快照窗口（设计 §7.6）；窗口边界必须与降级级别、可用性曲线同钟源同窗口定义（`REL-127`） |
| 上游输入 | 会话事件日志（真源） + 上传确认水位 + 派生视图（账本 / 计费 / 审计补写） |
| 频率 | 每窗口至少一次；差异未收敛的租户进入加密调度（间隔 ≤ 窗口 / 4） |
| 幂等 | 作业可重跑；同一窗口重跑必须产出相同结果（除已收敛项） |

### 3.2 差异计算

| 步 | 动作 |
|---|---|
| 1 | 由日志 + 水位派生 `log_derived`（金额与用量） |
| 2 | 读取派生视图 `ledger`（账本 / 计费） |
| 3 | 计算 `diff = log_derived − ledger`，按**方向**拆为 `diff_under`（`< 0`，少计 / 收入漏损）与 `diff_over`（`> 0`，多计 / 客户争议） |
| 4 | 计算 `diff_rate`，与绝对上限 `PP-26` 比对 |
| 5 | 未上传尾部量单独计算并**同窗**展示（§5） |
| 6 | 超阈差异进入裁定队列 |

### 3.3 幂等裁定回写（`REL-097`）

| 项 | 规则 |
|---|---|
| 裁定依据 | 真源（日志 + 水位）裁定；**不得**以两个派生视图互裁 |
| 回写键 | `(tenantId, turnId)`；同键重复回写只生效一次 |
| 计数 | 去重计数必须 +1（可观测） |
| 注入判据 | 对同一差异连续执行两次裁定回写 ⇒ 账本只变化一次，去重计数 +1 |
| 审计 | 每次裁定写审计（`{tenantId, window, diffDirection, amount, before, after, actor}`） |

## 4. 报表模板

### 4.1 字段（必填项缺失即模板校验失败）

| 字段 | 类型 | 必填 | 口径 | 来源 | REL |
|---|---|---|---|---|---|
| `tenantId` | string | 是 | — | 域令牌绑定值 | `REL-095` |
| `window` | object `{from, to, kind}` | 是 | `kind ∈ {T+24h}` | 作业参数 | `REL-095` |
| `logDerived` | object `{unit, value}` | 是 | 真源派生值（金额） | 日志 + 水位 | `REL-090` |
| `ledger` | object `{unit, value}` | 是 | 派生视图值（金额） | 账本 / 计费 | `REL-090` |
| `diffUnder` | object `{unit, value}` | 是 | 少计（收入漏损），**独立列** | 计算 | `REL-095` |
| `diffOver` | object `{unit, value}` | 是 | 多计（客户争议），**独立列** | 计算 | `REL-095` |
| `diffRate` | number | 是 | `abs(logDerived − ledger) / logDerived` | 计算 | `REL-095` |
| `absCap` | object `{unit, value}` | 是 | 每租户绝对上限 | `PP-26` | `REL-095` |
| `absCapBreached` | boolean | 是 | 是否触发上限告警 | 计算 | `REL-095` |
| `unuploadedTail` | object `{events, bytes, amount}` | 是 | 未上传尾部量（**必须与 `diffRate` 同窗**） | 水位 − 本地尾部 | `REL-096` |
| `rpoInNode` | object `{unit, value}` | 是 | 节点内 RPO（已 flush 前缀 = 0） | 本地 flush 水位 | `REL-094` |
| `rpoCrossNode` | object `{p99, unit}` | 是 | 跨节点 RPO = 复制滞后 | 水位差换算（`PP-06`） | `REL-094` |
| `unflushedTail` | object `{events, bytes}` | 是 | 未 flush 追加量（不得被 RPO 掩盖） | 本地计数 | `REL-013` |
| `convergeSeconds` | integer | 否（未收敛时填 `null` 并置 `converged=false`） | 首次观测 → 连续两窗归零 | 计算 | `REL-020` |
| `converged` | boolean | 是 | 是否收敛 | 计算 | `REL-020` |
| `reconciled` | boolean | 是 | 该行用量是否已对账（`false` 行必须出现在用量导出中） | 墓碑 / 差异状态 | `REL-056`、`PRD-036` |
| `boundaryNotice` | string（引用） | 是 | **边界声明**：对账只能发现「不一致」，**不能发现「伪造」** | `SEC-090` | `REL-098` |
| `generatedAt` | 时间戳 | 是 | 生成时刻 | 作业 | — |

> **禁止字段**：任何**无分层**的单一 `rpo` 字段。报表 schema 出现裸 `rpo` 即失败（`REL-094`）。

### 4.2 边界声明（`REL-098`）

| 项 | 规则 |
|---|---|
| 必填 | `boundaryNotice` 为必填字段；措辞本体归 `SEC-090`，本文件不复制措辞 |
| 不得省略 | 报表与合规说明两处都必须含该表述 |
| 禁止 | 全文**不得**出现「审计不可篡改」一类绝对化表述 |
| 校验 | 报表模板 schema 校验（必填字段）+ 合规模板评审 |

### 4.3 数值算例（校验用，非承诺值）

| 场景 | `logDerived` | `ledger` | `diffUnder` | `diffOver` | 合并差异 | 判定 |
|---|---|---|---|---|---|---|
| 少计 100 元 | 10,100 | 10,000 | **100** | **0** | 100 | 必须两列分别显示 100 / 0 |
| 多计 100 元 | 10,000 | 10,100 | **0** | **100** | 100 | 同上 |
| 两者各一笔 | 10,100 | 10,100 | **100** | **100** | **0** | 合并为 0 而两列非零 ⇒ **合并即失败**（`REL-019`） |

## 5. 未上传尾部量与容量

### 5.1 尾部量同窗展示（`REL-096`）

| 规则 | 内容 |
|---|---|
| 禁止规避 | **不得**通过缩小或滚动窗口规避「未上传尾部」 |
| 同窗绑定 | `unuploadedTail` 必须与 `diffRate` 在同一窗口同一行展示 |
| 注入判据 | 上传停滞 2 h ⇒ `diffRate` 与「未上传尾部量」**同时上升**；一升一平即失败 |
| 真实来源 | 差异的真实来源即「未上传尾部」，故它必须作为独立 RPO 指标暴露（`REL-014`、`REL-096`） |

### 5.2 上传吞吐容量（`REL-099`）

| 项 | 规则 |
|---|---|
| 基线 | `基线 QPS = 域数 / uploadInterval`；多为空转请求 |
| 推导（示例值） | `D = 1000` 域、`F = 5 s` ⇒ `1000 / 5 = 200 req/s`；若 `F = 30 s` ⇒ `≈ 33.4 req/s`（**两个候选值来自 `PP-25` 的冲突项**，须裁定后回填） |
| 预留 | 必须预留空转开销与抖动叠加后的峰值（补传令牌桶 `PP-14` 与常规上传共享入口，取二者之和为上界） |
| 压测 | 以基线 3× 的上传速率压测；观察上传路径无积压、不影响其他依赖 |
| 容量模型 | 该项必须进入容量模型（`REL-DOC-06` §5） |

## 6. 收敛、上限与幂等扣减

### 6.1 收敛时长（`REL-020`）

| 项 | 规则 |
|---|---|
| 参数 | `PP-08`（`T_h`） |
| 测量点 | 差异**首次被观测** → **连续两个窗口**差值均为 0 |
| 曲线约束 | 期间该租户差异率曲线必须**单调下降**；回弹即失败 |
| 注入判据 | 制造一笔 500 元少计：从首次告警到两窗归零的时长 ≤ `T_h` |
| 指标 | `recon.converge{tenant}`（`SLO-15`） |

### 6.2 绝对上限（`REL-095`）

| 项 | 规则 |
|---|---|
| 参数 | `PP-26`（每租户绝对上限，金额） |
| 触发 | 任一方向差异绝对值 > `PP-26` ⇒ 告警（硬告警级别见 `REL-DOC-12` §2） |
| 分列 | 少计与多计**各自**与上限比对，**不得**用净额比对 |
| 对客 | 分方向披露口径见 `PRD-041`；`T_h` 只能引用 `PP-08`，不得另写数值 |

### 6.3 用量扣减幂等（`REL-100`）

| 项 | 规则 |
|---|---|
| 幂等键 | `(tenantId, turnId)` |
| 去重 | 重复上传与重复消费必须被去重并计数：指标 `usage.dedup.count` |
| 注入判据 | 对同一 `turnId` 重复上传 10 次 ⇒ 账本扣减 1 次、去重计数 +9 |
| 与水位 | 去重必须在水位之内进行（水位界定已上传区间；水位内的重复即重复上传） |

## 7. 删除流程的对账可完成性（`REL-101`）

| 步 | 动作 | 断言 |
|---|---|---|
| 1 | 停写（取锁）→ 墓碑 → 删数据 → 释放锁（删除顺序） | 与迁移竞争不得发生（迁移准入见 `REL-DOC-07` §3.2） |
| 2 | 删除**前**抽出计费与审计所需的**假名化聚合**（口径归 `SEC-085`） | 抽取检查点必须成功；失败即阻断删除 |
| 3 | 审计留存冲突 | 对保留的审计做**假名化而非删除**（合法扣留优先） |
| 4 | 删除后对账 | 该窗口 T+24 h 对账**仍可完成**，差异率 ≤ 0.01% |
| 5 | 注入判据 | 对一个含未对账用量的会话执行删除流程 ⇒ 删除后 T+24 h 对账仍可完成且差异率 ≤ 0.01%（`DRL-E20`） |
